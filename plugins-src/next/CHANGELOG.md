# NEXT 更新日志

## 未发布

- Task 卡片新增“帮我开个头”：选择 agent、查看进度和结构化提问，保存人工答案后预填安放表单；只有用户提交才改变任务生命周期。
- 结果以独立 Task Kickoff 文档保存，重跑保留旧答案，保存答案保护手工修改的正文。模板和规程经首次确认后仅在缺失时添加。
- agent 的只读安全关卡与真实运行验证分开记录；尚未通过关卡的 provider 保持不可用。

## 1.10.0 — 2026-10-27

- 活动 Task 的安放菜单首项新增“完成并记一笔”，复用“接下来怎么办”窗口，预选完成并突出多行补充输入框。点击完成后，先把记录追加到任务 Markdown，再完成任务、播放礼花并触发现有提醒脚本。
- 保存失败保留当前输入供重试；同一次操作不重复追加记录或完成事件。原有快捷完成和“更多…”保持不变。
- 提醒脚本成功后显示其报告的新增、更新、撤下数量；无变更与缺少统计分别提示。保存环境变量明确说明仅保存到本机，尚未测试服务器连接。

最低宿主仍为 6.1027.1；脚本环境变量和具体失败原因需宿主 6.1027.2。本次只发布插件。

## 1.9.0 — 2026-10-27

- 提醒脚本设置新增多行环境变量输入，支持 DESK_DISPLAY_URL / DESK_DISPLAY_TOKEN，独立保存与清除、仅显示已配置变量名；旧宿主提示更新。配置仅用于本机 NEXT 调用，不同步到 Vault。

- 脚本同步失败时显示缺少 Cube 配置、无法连接、已有同步运行或服务版本不支持的具体原因；配套宿主保留脚本非零退出时的固定错误码，未知错误内容仍不显示。

- 项目标签、Idea / Task 和搜索筛选保留“显示已安放”开关；默认隐藏未到期的稍后项和已结束卡片，显式展开后只显示符合筛选的内容。

本版保持兼容宿主 6.1027.1；环境变量输入和具体失败码需配套宿主更新。当前旧宿主会提示升级，原有脚本选择与执行仍可使用。本次仅发布插件，不包含宿主更新。

## 1.8.0 — 2026-10-27

- 设置可选择 skills 中的 Python 同步脚本。Task 状态、提醒设置或期限保存后直接执行，不调用模型；失败独立提示并可重试，不重复修改任务。需配套新宿主 API、脚本依赖和本机 Cube 凭据。

## 1.7.1 — 2026-10-27

- 标签筛选区新增 Idea / Task，支持切换、取消，并与项目和搜索叠加。

## 1.7.0 — 2026-10-26

- 安放按钮提供现在推进、等待回收、以后再看、完成、停止、转移他人和“更多…”。快捷操作只改状态，更多才打开详细录入。
- 拖拽到其他泳道直接保存状态，不弹出输入框。
- 卡片可直接完成，保存成功后播放页面内礼花；遵循系统“减少动态效果”。
- Task 卡片新增提醒入口，支持暂停一小时、暂停到明天九点、关闭和恢复；详情可设置暂停终点。
- 提醒设置与任务状态分开，完成、停止、转移分别显示。关闭提醒不结束任务，重开不会自动解除静音或旧关闭记录。
- 修复原来没有期限的任务首次添加截止日期失败的问题。

提醒过滤需搭配更新后的 Vault 脚本。暂停到期只恢复候选资格，不保证准点发送。Agent CLI、skills 和远程运行器不包含在插件市场包中。
