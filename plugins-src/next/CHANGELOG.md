# NEXT 更新日志

## 未发布

- “开个头”改由 Agent 自行使用 `notemd search --vault` 检索相关上下文，并用 harness 联网检索近期相关文章；NEXT 只传计算的 Vault 路径、Task 身份和协议，不再预扫描或发送背景文件包。
- 复用各 Agent 可调整的最大并发设置（1–5），默认 3；不同 Task 可同时运行，同一 Task 保持互斥，进度按运行隔离。已有显式设置保留。
- 运行前显示检索范围与服务商；支持文章 URL 引用和系统浏览器打开，继续由 NEXT 校验并保存独立结果，不自动执行或安放任务。
- 新 v3 检索模式要求配套 Agent 更新；旧 v1/v2 运行与结果保持可读。外链打开和默认并发需配套宿主更新；发布时须提升最低宿主版本。本条为源码改动，尚未发布或安装。

## 1.12.1 — 2026-10-27

- 背景按数据源与目录公平分配扫描预算，中文标题支持部分词语匹配；已完成 Task 先从账本筛选再读取，避免大量未完成任务挤掉日记和批注。
- 每次运行（含重跑）先显示服务商、实际发送文件、大小与缺失背景；确认后发送同一份冻结内容，任务或规程改变必须重新确认。
- 引用来源限定为本次实际发送的文件，重启后仍校验；旧运行缺少快照记录时降低事实可信度。
- 使用独立 v2 任务模板，保留已有 v1 自定义文件；新模式要求 Agent 声明冻结 v2 协议能力。Claude 等未支持插件显示“暂不支持”。
- 锁冲突显示并行容量限制，不误报失联；运行时长保存为整数秒。

配套 Codex Agent 1.0.22 / DeepSeek Agent 1.1.21；最低宿主仍为 6.1027.1。

## 1.12.0 — 2026-10-27

- “帮我开个头”覆盖进行中的 Task；主操作与 Agent 选择合为一个有清晰分区的复合控件，菜单由本机已安装插件提供。
- 由 NEXT 收集当前 Task 与规程声明的相关背景，保留来源、时间窗口和缺失说明；关闭的数据源不会用于扩展背景，背景快照有文件数与字节预算。
- 配合 Codex Agent 1.0.21、DeepSeek Agent 1.1.20，在无工具模式下生成结构化问题；旧 Agent 缺少所需能力时提示更新，不再以固定的未验收标记禁用已支持版本。
- 保存答案、保护手工结果正文、重新生成与用户确认安放的既有行为保持一致；进行中的任务不会因打开问答自动变更生命周期。

- 损坏、重复或暂时不可读的结果仅影响所属任务；终态结果冲突记录失败并释放运行位置，保留原文件供修复。

最低宿主仍为 6.1027.1；本次不发布 Claude Agent。

## 1.11.0 — 2026-10-27

- Task 卡片新增“帮我开个头”：选择 agent、查看进度和结构化提问，保存人工答案后预填安放表单；只有用户提交才改变任务生命周期。
- 结果以独立 Task Kickoff 文档保存，重跑保留旧答案，保存答案保护手工修改的正文。模板和规程经首次确认后仅在缺失时添加。
- Agent 执行列表根据已安装插件动态显示，保留版本、模型与不可用原因，不固定为 Claude Code。
- 真实模型验收留待后续完成，当前各 Agent 的“帮我开个头”执行入口均不可用；已有结果仍可查看、回答和安放。最低宿主保持 6.1027.1，本次仅发布 NEXT 插件。

## 1.10.0 — 2026-10-27

- 活动 Task 的安放菜单首项新增“完成并记一笔”，复用“接下来怎么办”窗口，预选完成并突出多行补充输入框。点击完成后，先把记录追加到任务 Markdown，再完成任务、播放礼花并触发现有提醒脚本。
- 保存失败保留当前输入供重试；同一次操作不重复追加记录或完成事件。原有快捷完成和“更多…”保持不变。
- 提醒脚本成功后显示其报告的新增、更新、撤下数量；无变更与缺少统计分别提示。保存环境变量明确说明仅保存到本机，尚未测试服务器连接。

最低宿主仍为 6.1027.1；脚本环境变量和具体失败原因需宿主 6.1027.2。本次只发布插件。

## 1.9.0 — 2026-10-27

- 提醒脚本设置新增多行环境变量输入，支持 DESK_DISPLAY_URL / DESK_DISPLAY_TOKEN，独立保存与清除、仅显示已配置变量名；旧宿主提示更新。配置仅用于本机 NEXT 调用，不同步到 Vault。

- 脚本同步失败时显示缺少 Cube 配置、无法连接、已有同步运行或服务版本不支持的具体原因；配套宿主保留脚本非零退出时的固定错误码，未知错误内容仍不显示。

- 项目标签、Idea / Task 和搜索筛选保留“显示已安放”开关；默认隐藏未到期的稍后项和已结束卡片，显式展开后只显示符合筛选的内容。

本版保持兼容宿主 6.1027.1；环境变量输入和具体失败码需配套宿主更新。当前旧宿主会提示升级，原有脚本选择与执行仍可使用。本次仅发布插件，不包含宿主更新。

## 1.8.0 — 2026-10-27

- 设置可选择 skills 中的 Python 同步脚本。Task 状态、提醒设置或期限保存后直接执行，不调用模型；失败独立提示并可重试，不重复修改任务。需配套新宿主 API、脚本依赖和本机 Cube 凭据。

## 1.7.1 — 2026-10-27

- 标签筛选区新增 Idea / Task，支持切换、取消，并与项目和搜索叠加。

## 1.7.0 — 2026-10-26

- 安放按钮提供现在推进、等待回收、以后再看、完成、停止、转移他人和“更多…”。快捷操作只改状态，更多才打开详细录入。
- 拖拽到其他泳道直接保存状态，不弹出输入框。
- 卡片可直接完成，保存成功后播放页面内礼花；遵循系统“减少动态效果”。
- Task 卡片新增提醒入口，支持暂停一小时、暂停到明天九点、关闭和恢复；详情可设置暂停终点。
- 提醒设置与任务状态分开，完成、停止、转移分别显示。关闭提醒不结束任务，重开不会自动解除静音或旧关闭记录。
- 修复原来没有期限的任务首次添加截止日期失败的问题。

提醒过滤需搭配更新后的 Vault 脚本。暂停到期只恢复候选资格，不保证准点发送。Agent CLI、skills 和远程运行器不包含在插件市场包中。
