# Bundled cmarker

This directory vendors cmarker 0.1.10 from the Typst Universe package archive:
`https://packages.typst.org/preview/cmarker-0.1.10.tar.gz`.

- License: MIT (see `LICENSE`)
- Upstream: https://github.com/SabrinaJewson/cmarker.typ
- Package archive SHA-256: `7e5d7a0365aa1d32273bddb4511c62e47ab9d63093c905184ba04ca62064aafc`

Only `lib.typ` and `plugin.wasm` are required at runtime. The package is kept
offline and pinned so opening a book never downloads executable code.
