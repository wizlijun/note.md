# DeepSeek Agent 更新日志

## 未发布

## 1.1.21 — 2026-10-27

- 声明并支持 NEXT 冻结 v2 协议：只消费确认后的完整 prompt，不重复读取磁盘 AGENTS.md 或 task.json 指令；缺少 v2 标记或只读/预算配置不合规时拒绝执行。
- 任务锁占用生成 capacity 终态记录，保留原运行，避免调用方误判失联。

## 1.1.20 — 2026-10-27

- 支持 NEXT 提供冻结背景快照的无工具执行：使用隔离临时工作目录并关闭 ACP 工具，拒绝文件、命令、网络和 MCP 调用，只返回最终结构化结果。
- 向插件调用方声明此能力；保持普通任务原有执行模式，隔离模式不执行预检查、不生成或扫描交付文件。
