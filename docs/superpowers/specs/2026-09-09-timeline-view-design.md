# Timeline 显示插件

## 目标与边界

新增 `notemd.timeline`，将 frontmatter `type: timeline`（忽略大小写）的 Markdown 在富文本模式中显示为竖向日程。文档仍是 Markdown，源码切换、保存和外部变更使用宿主现有链路。插件不改写文档；加载失败、无响应或任一时间项解析失败时回到 Markdown 编辑器。用户主动编辑后保持编辑状态，点击返回视图或切换模式再尝试显示。

## 样本与解析契约

只读检查 diary 下全部 468 篇 `YYYY-MM-DD.timeline.md`，涵盖 2025-05-29 至 2026-09-08：一级活动 6633 条，子议题 1655 条，空日 7 篇，零时长 1671 条，434 篇存在交叠。

支持独立 YAML 分隔行、`Timeline` 类型、日期标题/摘要/说明，以及 `- HH:mm:ss–HH:mm:ss — 动作：描述 [来源](relative.md#line10)`。兼容分钟精度和常见连字符，保留秒精度、零时长及嵌套议题。时间须有效且结束不早于开始；允许 24:00 作为终点，倒序跨夜记录交给 Markdown 编辑器。任一不支持的列表或损坏条目整体回退，不能静默漏项。正文说明保留可见。来源只打开当前 Vault 内相对文件，现有 host.editor.open 只定位文件，不承诺行锚点跳转。

日程按开始时间排序；左侧时间刻度，时间块按时间定位，短活动设最小可点击高度，重叠活动分列。子议题在父活动详情中展示并继承分类。时段交叠不累加为投入时长。

## 分类

固定大类：工作（浅蓝）、兴趣（浅绿）、生活（浅粉）、休闲（浅灰）、其他（白）。设置包含有序规则：名称、关键词数组、所属大类。**只对活动类别文字做关键词包含匹配**，忽略大小写，不匹配正文，不做语义推断；规则从上到下首条命中，未命中为其他，空关键词无效。规则名称仅用于管理。

默认按样本常见动作分组：审阅/审查/评审，开发/修复/测试/发布，沟通/会议/讨论，设计/组织/规划属于工作；阅读/学习/实验/实践等属于兴趣；家庭/出行/采购等属于生活；聚餐/散步/娱乐等属于休闲。用户可新增、修改、删除和调整规则顺序。

设置在插件内部页面编辑，`host.settings.get/set` 存在插件域 `classification` 键；保存成功后立即生效，取消不改变现行规则，读取/保存失败可见且保留草稿供重试。manifest 不贡献系统设置表单。

## 宿主契约

正式版本使用 [文件规则视图宿主能力](2026-09-09-file-views-host-design.md)：Timeline 在 `contributes.file_views` 中声明 Markdown 扩展名与 frontmatter `type: timeline` 条件，宿主负责选择、`file_view.*` 握手、失败回退和源码优先。文件文档保持 Markdown，插件没有文档改写权限。上一轮未发布的 `markdown_types` 草案已被正式通用接口取代。

Timeline `1.0.0` 与宿主 `6.909.1` 配套发布，最低宿主为 `>=6.909.1`。
