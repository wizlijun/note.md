# Power Mode 素材与 Sumi 后台迁移

状态：2026-11-08 用户已确认实施；取代旧候选仅拆字体后立即发布的计划。本文件补充 `2026-11-07-immersive-write-design.md`，不降低原生输入、逐行时间、离线合并、恢复及安全存储要求。先实现、验证，再按既有通道发布宿主及两个插件。旧 v6.1108.3/v6.1108.4 草稿与 Sumi 0.1.2/0.1.3 R2 对象不可改写或误上架。

## 目标与范围

1. Power Mode 的13个GIF由Power Mode插件交付；宿主不再包含原文件或其编码副本。宿主保留主编辑器与Editor Kit的效果挂载、输入事件和配置薄桥。未安装/停用插件不加载素材。
2. Sumi已有设置UI仍在插件中；新增平台原生可执行后台，承担字体下载/校验/缓存、SQLite持久化/Markdown投影、网络传输及后台同步。宿主保留AppKit编辑surface、即时内存CRDT/选区映射、IME事务、Tab/焦点和系统服务桥。后台接管工作不能使每次输入等待IPC。
3. 本轮不拆Memory/Habitat，不移除共享公式/图表/分享编辑器，不新建dylib插件体系。宿主包、插件包及安装后合计分别报告，不用源码大小推算节省量。

## Power Mode 资源契约

- 固定13路径无损移动到插件public目录，经现有UI打包。GET仅读已安装启用Power Mode的这13个GIF；校验文件身份/包含关系、类型，拒绝路径穿越、软链接逃逸和任意文件访问。
- Kit经请求方自身origin的只读资源路由获取；主窗口经窄系统命令获准资源描述。不得放宽插件CSP，也不得从插件加载脚本进入宿主。
- 描述返回ready/missing/disabled，不把资源地址混入用户持久化配置。旧插件缺素材时禁用爆炸并明确提示更新，combo/shake可继续；不得出现破图或偷偷回退宿主内置副本。新插件预览、主窗口、Kit三处均须验证。

## Sumi 服务与保存边界

- 使用现有签名原生插件子进程/stdio JSON-RPC、生命周期监督和安装路径。宿主专用服务请求与WebView `ui.request`分离；UI不能冒充宿主绑定Vault、文件缓存或数据库路径。
- 每个会话绑定规范化Vault、服务协议版本和进程实例；重启先重新绑定，旧实例事件不得写入新会话或切换后的Vault。后台不能同时打开同一工作区的两个写所有者。
- 宿主输入事务只执行内存编辑和有界入队；入队成功不等于已保存。队列背压或服务不可用时保留可恢复状态并显示未保存，不伪报成功。
- `Committed`仅在SQLite WAL事务成功后发出；投影成功另报`Saved`，错误仍可重试。跨进程编辑带稳定op_id、page/epoch/generation/revision和内容摘要。后台持久收据与数据同事务提交；重放同请求返回原确认，同op_id不同内容拒绝。收据不能因云端ACK删除outbox或checkpoint清理delta而丢失。
- 宿主保留未确认编辑，后台崩溃后按顺序重放；不能重复创建纸页、目录操作或导入。读/flush必须排在已接受修改之后。远端收取先持久inbox，再经宿主IME/版本屏障应用，应用确认后更新持久状态，不因管道成功便推进同步游标。
- 保留现有SQLite、Markdown/sidecar与字体缓存路径和内容；迁移只是写所有权转移，不清空或重新配对。关闭窗口不停止下载/同步，退出/插件停用或升级须先完成保存排空；失败不得把未保存编辑默默丢弃。

## 凭据与字体

- 长期设备密钥仍由宿主Keychain封装，沿用现有身份；不传给WebView、不写配置/Vault/日志。配对与短期token获取的窄认证代理留宿主；后台只能获得当前绑定工作区所需的短期访问凭证。不得要求用户为迁移重新提供密钥。
- 字体目录/授权随Sumi插件交付；只点击时开始后台下载，状态请求/首开/默认字体不联网。后台任务独立于设置窗口。固定HTTPS来源、size/SHA、ZIP单成员及原子缓存保持不变；CoreText注册和IME安全应用留宿主，最后选择优先且不覆盖同期主题/字号。

## 验收与发布

- Power：13素材摘要/功能三处一致；未装/停用/旧版/跨插件越权/路径逃逸负例；宿主产物不再含13GIF原始或压缩资源，插件实际包包含它们。
- Sumi：真实独立进程测试，包括保存前/后杀进程、丢响应重放、同ID异内容、checkpoint/云ACK后重放、队列顺序/背压、并发Vault、退出/升级/停用、窗口关闭继续下载、无隐式下载、输入/IME与远端合并、恢复旧数据库/路径。只使用隔离Vault。
- 原生后台发布必须Developer ID签名（缺身份即失败），runtime/timestamp，Apple公证Accepted关联最终二进制；市场minisign不能替代Apple签名。完整包回读后再核后台二进制身份及签名。
- 冻结新tag实际源码和实际App/DMG/updater/插件包；保全所有worktree/分支/stash及无关改动。当前候选版本目标host6.1108.5、Sumi0.1.4、Power Mode1.0.4，发布前核无冲突。
- 沿用仓库Wrangler3+Account Token：R2包/签名→匿名普通/fresh全量回读验签→兼容宿主公开→KV追加→公网复核。不得重写旧发布对象。
