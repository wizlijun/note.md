# Sumi macOS 窗口启动

用户要求新建窗口根据实际显示器协调布局，允许绿色按钮进入全屏，并提供默认开启的启动全屏选项。

范围仅Sumi独立窗口：普通note.md窗口、嵌入写作标签页不自动全屏。使用当前目标显示器逻辑工作区，考虑缩放、菜单栏和Dock；初始窗口有合理边距，大小上下限不能超出小屏工作区。开启原生全屏能力而非模拟无边框最大化。

偏好字段建议appearance.startFullscreen，默认true，缺少字段按true读取，明确false保持；界面只承诺下次打开新独立窗口时生效。再次激活已经打开的窗口不夺走用户选定的非全屏状态。启动顺序确保窗口显示、编辑器挂载与全屏过渡不会丢失焦点、组字或错误关闭草稿。

验证：不同逻辑尺寸与非零屏幕原点；默认/旧配置/false持久化；绿色按钮进入、退出恢复合理窗口尺寸；当前原生字号全屏缩放保持；正文保存重开。发布证据与工作区验收分开。
