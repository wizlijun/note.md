# Sumi Linux 组字声音

## 根因
真实私有 Fcitx/Wayland 输入 nihao，正文尚未提交时没有任何 TypingSoundEvent。输入法在 TextView key-press-event 前消费组字键；只监听该事件不能覆盖组字。当前安装宿主也实际加载 im-wayland.so。

## 实现与边界
在非空 preedit 内容发生变化时发 Key 声音，复用原有音效 handler、身份及队列。重复文本刷新、清空/提交、程序投影、隐藏/失焦/失败表面不补声。若当前 GDK 按键事件已经发声，以时间戳和硬件键码识别同一次事件，不做时间节流。普通按键与释放沿用原入口。
这是输入法组字反馈；输入法未转发且不改变组字内容的候选导航键不凭空合成声音。不修改输入法设置或安装配套模块。

## 验证
隔离 Sway、D-Bus、Fcitx，分别以 fcitx 与 wayland GTK IM 模块运行真实拼音输入，要求 nihao 提交前恰好五个 Key 事件；验证组字刷新/清除不重复、关闭音效、英文按键和正文事务回归。修复前新断言得到 0 而非 5。测试 handler 收集生产音效事件，不播放声音或改用户音量。正式包安装与发布另行执行，不用源码验证冒充已安装。
