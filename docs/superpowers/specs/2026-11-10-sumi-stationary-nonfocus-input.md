# 非聚焦输入行保持原位

用户最新要求替代此前“正文输入行也固定底部”：非聚焦模式保持用户光标、正文行及滚动位置，仅候选区在编辑视区底部左对齐展开，最多四行。候选出现、翻页、行数变化和消失不得触发正文底部锚定、改变正文上下边距或压缩正文 viewport。普通编辑引起的自然换行/滚动仍由 GTK 处理。专注模式仍在当前输入行下一行显示候选。

实现：删除候选引入的 bottom_anchor 状态及其触发路径；正文始终使用宿主分配的完整 bounds；候选作为不参与正文布局的覆盖层；布局变化只更新候选自身。独立光标在候选覆盖范围内不得穿透候选绘制，且不借此改变正文 selection 或 scroll。

验证：真实 GTK + Fcitx 拼音记录组字前后 caret Y、scroll adjustment 和文本 viewport。候选由零到真实候选、由一到四行、清空候选时保持正文坐标与选区；对多行文档滚动后的中部位置同样检查。保留专注下一行、实际选词提交、草稿失败、其他输入框隔离和重连回归。仅在隔离显示环境测试，不修改用户正文。
