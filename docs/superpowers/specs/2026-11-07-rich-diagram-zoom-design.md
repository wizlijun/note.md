# Rich 图表缩放与平移设计

日期：2026-11-07。状态：已实施并完成自动化验收，未发布；Mac物理输入验收仍为发布门槛，不属于已发布的 6.1107.2。

用户目标：鼠标停在图表渲染块时，直接使用滚轮或触摸板手势放大、缩小，查看细节。

**已确认的关键决定：图表内直接滚轮缩放，图表外滚动页面，不要求 Ctrl/⌘。** 以下参数与细节为评审后的实施约定，不能更改已确认的滚轮策略。

## 1. 范围

首版覆盖桌面 Rich 编辑器中 Mermaid（含 Pele 渲染后端）、DOT/Graphviz 的成功 SVG 预览，同一套操作用于可编辑与只读文档。以后新增渲染器须显式声明兼容，不能因内容里存在一个 SVG 就接管其内部交互。

普通代码块、源码模式、普通图片、Canvas、表格及其他具有自身交互的渲染器不接入。网页分享、独立 Editor Kit、PDF/图片导出本轮不自动开启；移动端触屏双指操作也不属于本轮承诺。桌面触摸板与触屏不能混为一种设备。

沿用6.1107.2的“始终显示图表工具栏”偏好。该偏好只控制显隐，不影响手势能否使用；不新增全局缩放偏好或文档配置。

## 2. 用户交互

### 2.1 目标区域与手势

| 操作 | 在成功图表的预览视口内 | 在工具栏、正文、图外空白处 |
| --- | --- | --- |
| 普通纵向滚轮 | 直接缩放当前图表，上滚放大、下滚缩小 | 保持页面原有滚动 |
| 触摸板双指捏合 | 张开放大、合拢缩小 | 保持宿主原有行为 |
| 触摸板双指纵向滚动，被系统转换为 wheel | 与滚轮一致，缩放当前图表 | 滚动页面 |
| 左键拖拽图表 | 有溢出的方向平移 | 保持原有行为 |
| 工具栏 − / + | 以图表视口中心缩小/放大 | 仅作用于所属图表 |
| 点击工具栏倍率 | 恢复默认大小100%与初始位置 | 仅作用于所属图表 |
| 点击“适应视口” | 完整显示当前图，不放大原本较小的图 | 仅作用于所属图表 |
| 点击方向按钮 | 沿溢出方向移动，无需拖拽 | 仅作用于所属图表 |

不能可靠地从 wheel 的 deltaMode、数值大小、频率推断设备种类。因此首版不承诺“鼠标滚轮缩放、触摸板双指纵移却平移”的区别。横向且 deltaY=0 的普通 wheel 不触发缩放，也不额外拦截；平移使用拖拽、方向按钮或方向键。

滚轮目标范围为工具栏下方的预览视口，包含图形周围的内部留白，但不包括工具栏、加载提示、空图、渲染错误和隐藏源码。纵向缩放意图一经图内处理，即使已达最小/最大倍率也须消费该事件，不能突然变成页面滚动或整页缩放。

浏览器可能把一串 wheel 的事件目标固定在起始元素，因此不能承诺同一连续滚动中每次都立即切换到新消费方。新滚动序列在图内开始就直接缩放；在图外开始就维持页面滚动。图内序列移出原图后停止变换，其可取消的尾事件仍被消费，不能突然滚页或缩放相邻图；停止滚动后在图外重新滚动即可滚页。没有原生 phase 时，以连续150ms无事件结束应用序列，不据此猜测设备。明确的捏合 start/end 锁定同一张图到结束。

路由监听限定在该编辑器所属的滚动容器，capture、非passive，按指针坐标与注册的成功视口边界判定新序列归属，不依赖可能被锁定的event.target。不在window/document上拦截所有滚轮。不可取消的事件不再执行图表变换，避免图表与页面同时缩放；真实WKWebView序列另设发布验收门槛。图外序列不取消默认行为。

### 2.2 缩放中心、速度与限制

- 滚轮以鼠标所在点为中心。手势提供可靠中心时使用该中心；没有中心时使用本轮最近有效的图内指针位置，最后回退视口中心。不得使用上一个图的坐标。
- `100%` 是该图在当前正文宽度下原有的默认渲染大小，并非物理像素原尺寸。初始显示效果与现有版本一致，不强行放大小图填满宽度。
- 通常倍率范围 **50%–400%**，长图为完整显示允许下限降到`min(50%, 适应视口倍率)`；滚轮与捏合连续变化，按钮每次乘/除1.25并限制范围；展示倍率四舍五入为整数，内部保留精度。
- 捏合结束不吸附回某个整数倍率。到达边界后保持不动，不反弹、不接续滚页。
- 缩放应尽量保持鼠标下面的图中位置不动；仅当居中/平移边界限制要求时允许位置调整。
- wheel按deltaMode归一化，单个大delta有界处理，连续小delta保留精度，使用requestAnimationFrame合并绘制。具体灵敏度在真实鼠标/触摸板验收时校准，不增加设置项。

### 2.3 平移与布局

- 小图按未缩放排版确定视口尺寸。长图的整个预览块（含工具栏）高度上限为`min(560 CSS px, 编辑器可见高度 × 70%)`；可见高度取所属编辑器滚动容器与可视窗口的交集，不能只取window.innerHeight。先扣除工具栏实际换行后的高度，再确定视口；极小窗口优先保证工具栏与滚页空间，不能用最小图高反向撑高整个块。缩放只改变视口内部内容，**不扩大图表块高度、不推移后面的正文、不缩放工具栏**。
- 预览两侧各保留24 CSS px的图外滚页通道，不计入缩放命中范围。“适应视口”按宽高同时计算完整图倍率，最大为100%；与恢复100%的语义分开。长图初始仍为默认宽度的100%，从图的顶部开始显示；点击倍率恢复100%也回到顶部，避免打开就落在长流程中段。无溢出的方向居中，“适应视口”完整居中显示。
- 内容超出视口时裁切，允许左键拖拽查看；不足以溢出的方向居中且不能拖离中心。溢出方向限制平移范围，不能将整个图拖出视口留下全空白。
- 指针按下到移动超过4 CSS px才进入拖拽；拖拽期间使用pointer capture与grabbing光标，松开、pointercancel、失焦或销毁必须终止。无可平移方向时保持普通指针。
- 拖拽不选中文档正文、不触发链接、不改图表源码。图内链接在未跨过拖拽阈值的单击时沿用既有安全打开链路；不能在pointerdown直接导航。
- 四个方向按钮始终占据固定的布局空间，每次移动40 CSS px，并在边缘或对应轴无溢出时禁用；避免缩放后突然出现按钮导致工具栏换行、推移正文。方向键同样移动40 CSS px。
- 页面滚动可通过图外通道、工具栏/正文区域、页面滚动条和原有PageUp/PageDown操作完成；跨界连续wheel遵循2.1的序列规则。滚动容器中的路由只消费图表拥有的序列，不给整个页面设置touch-action:none。

### 2.4 点击语义与工具栏

当前Mermaid在预览mousedown立即切入源码，而Graphviz没有同样行为。开启新图表交互的Rich场景中，两者统一为：**单击预览只聚焦/选择图表查看区域；编辑通过现有“代码”按钮进入。** 这项改变是避免拖图、缩放或点图中链接时误进源码的必要组成部分。

右侧工具栏顺序为 `−  100%  +  适应视口  ← → ↑ ↓  |  代码  复制`：倍率随当前值变化，倍率按钮恢复默认大小，“适应视口”完整显示长图。保留类型标签与语言选择入口。缩放控制只在成功图表预览时出现，源码/加载/空图/错误态不显示无效缩放按钮。

- −/+在对应边界禁用；倍率按钮名称说明“恢复默认大小（100%）”，并提供当前倍率给辅助技术。
- 关闭“始终显示图表工具栏”时继续悬停/选中/焦点显示；正在缩放或拖拽时临时保持可见，结束后按原显隐规则恢复。
- 手势说明使用简短tooltip：“滚轮或双指捏合缩放，拖拽移动”；不加每次弹出的教学层。
- 窄宽度可让整组控件换行，保证代码、复制和恢复可到达；不把它们藏进新增菜单，不遮住图。
- 成功且启用交互的图表预览始终预留当前工具栏所需的行高，包含窄屏换行后的高度。关闭常显只隐藏控件，不移除这块布局空间；悬停/手势/焦点带来的显隐不得覆盖图表或推移正文。窗口改宽时可以重新计算行高。
- 提供四语文案及有名称的查看region、清晰焦点；Tab/Shift+Tab正常离开。区域自身聚焦时 `+/-` 缩放、`0` 恢复、方向键平移。仅处理无Ctrl/⌘/Alt按键（允许输入+所需的Shift）；IME组合期间不处理。倍率以手势结束或短暂静止后的polite状态播报，不逐帧朗读。
- 代码、复制、缩放、适应视口与平移按钮均使用原生button的click激活，同一动作支持鼠标及Enter/Space，不能mousedown与click重复执行；剪贴板权限所需的ClipboardItem创建仍在用户激活回调内。
- 不能把滚轮缩放强制转为编辑器文本焦点，或在滚页经过图表时无故改变选区。

### 2.5 焦点、选区与编辑交接

- wheel/pinch不主动抢焦点、不修改ProseMirror选区。点击或Tab聚焦查看区域时，DOM焦点留在region，同时通过不入历史的选区事务将正文选区定位到当前图源码起点；不选择整块，避免之后Backspace误删整图。查看区域不接受正文输入。
- toolbar按钮拿DOM焦点，不把编辑器焦点抢回；只读模式允许查看/复制/切换源码显示，不能获得可写正文。代码按钮显式进入源码，可编辑时将光标放在当前代码块内部并聚焦；切回预览将焦点放回region。
- Esc终止手势，不改倍率；从当前图位置寻找图后最近可输入文本位置，找不到再找图前。两侧没有文本时停在当前源码内部的安全选区，不创建段落、不删除图、不返回远处旧光标。只读模式仅返回编辑器DOM焦点。
- NodeView销毁或删除时停止捕获，不能保留指向旧DOM的焦点回调。选区位置从最新getPos/事务mapping取得，不能缓存绝对位置。
- 宿主capture阶段的快捷键必须识别图表查看区/工具栏，将正文编辑快捷键留在查看上下文外；NodeView.stopEvent无法拦住宿主的capture。不得因Ctrl/⌘组合键用旧选区修改远处正文，浏览器常规Tab导航与IME不受影响。

## 3. 视图状态与文档边界

状态 `{scale, translation}` 属于文档会话内的图表块身份，不以NodeView实例寿命为用户状态寿命。缩放/平移不改变Markdown，不产生文档修改事务、不标记dirty、不进入撤销/重做历史，不保存进frontmatter、图表源码、Vault或全局settings。

| 事件 | 规则 |
| --- | --- |
| 首次打开/关闭后重新打开/替换整篇文档 | 100%及初始位置 |
| 无关正文编辑/NodeView重建/同一打开文档临时切换tab | 保留状态；通过会话内事务mapping或受控快照交接，不生成持久UUID |
| 同一图表代码↔预览切换且源码未改 | 保留视图状态 |
| 图表源文本或语言改变 | 新图成功渲染后恢复100%与初始位置 |
| 主题变化且源码相同 | 保留倍率，按新几何调整平移边界 |
| 正文宽度改变 | 先按现有渲染器适配新宽度，保留相对倍率与尽量相同的视口中心内容，再约束边界；不因缩放触发宽度重渲染循环 |
| 渲染失败/被删除/编辑器关闭 | 终止手势、清理观察器/监听与捕获，错误内容不捕获缩放 |

删除的图释放状态；复制或粘贴相同源码的新图获得独立身份。内存状态随文档会话关闭释放，不用源码字符串作为跨图缓存key。

复制PNG仍复制**完整原图**，不复制当前裁切区域，不因查看倍率而改变导出比例、背景或画质策略；源码复制仍是原代码。导出/分享照原文档渲染，忽略本地查看状态。

## 4. 实现边界

### 4.1 统一NodeView控制器

在 `moraya-core/src/plugins/code-block-view.ts` 的统一图表NodeView生命周期中接入轻量可销毁的视口控制器，Mermaid与renderer复用。宿主通过一个明确能力开关启用本功能，未启用的共享消费者保留原有行为；不引入Canvas引擎或大型缩放依赖。

结构分为：稳定预览视口 → 变换层 → 渲染器内容容器 → 原SVG。渲染器仍负责原SVG及其清理。缩放和平移只施加于SVG外的变换层，不修改SVG的viewBox、尺寸属性和绘图内容；复制原始SVG时不带视图变换。

复制尺寸的后备路径也须排除祖先变换：当前无viewBox时使用getBoundingClientRect的逻辑会读到缩放后的尺寸，实施时应使用控制器记录/更新的未变换布局尺寸或等价的原图测量。不能只移除clone上的transform就声称已保留原图大小。

宿主接线须覆盖 `src/lib/editor-bridge.ts` 的实际file-backed和现有兼容Rich挂载路径，不能只测试一个孤立helper。core中原Mermaid mousedown切源码必须按能力开关调整，不能靠宿主捕获事件与原监听竞速。

新增能力进入NodeView工厂/缓存身份时须检查 `moraya-core/src/setup.ts` 的tier1共享缓存键与异步pending键，避免开启缩放的Rich与未开启的share/Editor Kit串用工厂。具体公开类型沿现有core配置组织，只增加本功能所需字段。

### 4.2 手势适配

- 每个编辑器滚动容器仅一个wheel路由，成功视口注册/注销；最后一个视口注销时释放路由。具体手势监听放在视口。需要取消默认行为的监听显式非passive，只有已接受的图内序列才preventDefault；先判断可取消能力。
- 标准路径处理wheel，包括系统以ctrlKey=true表示的触摸板捏合；无需用户按Ctrl。对用户实际按Ctrl/⌘在图内滚轮仍只缩放图表，不能叠加整页缩放。
- macOS WKWebView/Safari可能提供gesturestart/change/end及相对起点的scale；需要单独适配，使用起始倍率×相对scale，不能每帧累乘而指数暴涨。
- 原生GestureEvent与兼容wheel必须互斥/去重，一次捏合不能执行两遍。具体仲裁以实际最低支持系统和当前系统的事件序列验证为准；事件特性检测不等于真机功能已验证。
- 同一图处理自身输入；图外或不支持交互的图不受影响。双指旋转不添加旋转功能。

### 4.3 渲染与生命周期

Mermaid保留并扩展generation守卫；renderer路径目前不完整，本轮必须补齐。每次render在独立结果容器内运行，加载后和render完成后均核对generation、语言、源码、编辑模式及destroy状态，只有当前成功结果才提交到live视口并绑定控制器。过期结果调用对应module对其独立容器清理，不能触碰新结果；同源码切语言也必须失效。新渲染开始、源码/语言变化、进入源码和destroy均使旧generation失效。控制器不得保存失效SVG引用，不得重复注册监听。

缩放过程只更新变换，不调用Pele/Mermaid/Graphviz重新布局。宽度观察针对未变换视口，避免transform改变测量结果后触发重渲染回路。文档移除、语言切换、渲染失败、编辑器销毁均解除事件、指针捕获和observer。

修改core后需构建并同步可分发dist，核对宿主安装依赖逐字一致；core源码测试通过不能代替宿主实际消费链验证。

## 5. 验收标准

1. **用户选定策略**：普通鼠标在图内滚轮立即缩放，无修饰键；图外、工具栏滚动页面。触摸板捏合缩放；系统转成wheel的双指纵移同样缩放。不存在设备猜测分支。
2. **目标与中心**：至少两张相邻图，仅命中的图变化；不同位置鼠标锚点稳定；边界居中/约束外，锚点漂移不超过2 CSS px。具有明确start/end的捏合在图外开始时不被图表接管；图内/图外起始的wheel序列、跨界尾事件、150ms间隔后的新序列分别按2.1验证；event.target锁定时仍正确命中，非cancelable不叠加图表变换。
3. **范围与性能**：通常50%/400%及长图fit下限正确限制，缩放端点不漏给页面；小delta连续、大delta受限、三种deltaMode可用；持续手势每帧至多一次视图更新，不重新运行renderer。
4. **布局与移动**：放大不推移后文或缩放工具栏；拖拽能查看溢出四边，不能拖成全空白；图外松开/pointercancel/失焦可结束；长图高度上限、图外24px通道、适应视口与非拖拽平移均可用。手势不选正文、不误切源码。
5. **编辑入口**：Mermaid/Graphviz单击均不进源码；代码按钮能切换，编辑源码后重渲染正确，未改源码的切换保留倍率。图内链接单击与拖拽互不误触。
6. **状态隔离**：缩放前后raw字节、dirty与撤销深度均一致；多图状态独立。主题/窗口尺寸/源码改变/语言切换/NodeView重建/临时tab切换/关闭重开按第3节执行。单独验证同源不同语言、两次render逆序返回、render中删除/销毁，晚到结果不写liveDOM且不清理新结果。
7. **复制与导出**：400%且已平移裁切时复制仍是完整原图；源码未改；PDF/分享不带裁切和倍率。无viewBox的SVG也不因CSS变换改变复制尺寸。
8. **发现性与无障碍**：常显开关两种状态、所有按钮Enter/Space单次激活、+/−/0/方向键、Tab离开、Esc交接、IME、只读文档、深浅主题，以及侧栏打开后实际编辑区390px/更窄宽度可用。常显关闭时聚焦/手势仍可达；控件换行不裁切、复制/恢复不丢失；Ctrl/⌘编辑快捷键不得修改旧选区正文。
9. **核心兼容**：开启/关闭能力的两个编辑器并发、loader/registry不同、初始化完成顺序相反时不串配置；未启用的share/Editor Kit及普通代码行为不变。
10. **真实平台**：发布支持Mac前，必须在实际候选WKWebView中验证物理鼠标滚轮与Mac触摸板捏合/双指滚动，确认手势不被系统/页面缩放抢走或重复处理。Chromium合成wheel测试仅为自动化补充。Windows/Linux要声称支持时分别完成WebView2/WebKitGTK目标平台验收；本spec不提前承诺已支持。

## 6. 依据与待实施验证

仓库依据（以6.1107.2/core e01e451b为基线）：统一图表DOM、Mermaid点击进源码与原SVG复制见 `moraya-core/src/plugins/code-block-view.ts`；宿主样式见 `src/styles/editor-base.css`、`src/styles/editor-structure.css`；挂载见 `src/lib/editor-bridge.ts`。Canvas已有捏合缩放能力，但本轮不引入其整套引擎。

平台资料：

- [MDN wheel事件](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)：滚轮、触摸板wheel、可取消性与passive边界。
- [MDN ctrlKey](https://developer.mozilla.org/en-US/docs/Web/API/MouseEvent/ctrlKey)：触摸板捏合可能产生ctrlKey=true的wheel。
- [Apple GestureEvent](https://developer.apple.com/documentation/webkitjs/gestureevent)与[scale](https://developer.apple.com/documentation/webkitjs/gestureevent/1632653-scale)：原生手势与相对起点比例。

本轮实施控制器与隔离事件探针，记录自动化可验证部分及真实硬件验收缺口。发布Apple Silicon候选前，必须采集目标WKWebView的物理鼠标/触摸板事件序列，验证取消、跨界、去重与灵敏度；无法取得硬件输入时保留该发布门槛，不凭合成事件或API文档宣称通过。不修改6.1107.2冻结tag。
