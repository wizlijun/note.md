# 分享项目主界面规范化

以已实施的项目分享能力为基础，按用户要求与宿主其他界面一致。依据 `2026-09-05-settings-plugin-ui-review.md` 和 SettingsDialog；不改变 Worker、文件集合、反馈协议和原件写回逻辑。

## 设计

- 采用设置窗口相同的桌面模态外壳：12px 圆角，17px 标题、13px 正文、12px 辅助文字，统一 `--ui-*` 色彩和焦点环。
- 左侧约182px持久导航，包含「分享内容」「反馈收件箱」；右侧独立滚动。使用 nav + aria-current，窄窗口转为横排导航。
- 项目选择为上方独立区域：最近项目与「选择项目…」；已选项目显示名称、完整路径和发布状态。没有项目时显示简洁空态与选择入口。
- 分享内容按「入口文档 → 文件范围 → 分享链接」组织。文件列表用紧凑行、入口标记、文件大小，简短说明默认隐私排除。详细规则/引用问题仅在相关状态显示。
- 底部固定显示范围摘要与唯一发布主按钮；重试保留原冻结包语义。保存并扫描为范围标题旁的次操作。
- 阅读与协作链接操作明确区分；停止分享、重新绑定置于可展开的项目管理，保留原确认行为。
- 收件箱独立分区，待审阅数量清晰；列表、逐文件对照、最终写回文本和旧快照标注沿用已验证流程。导航切换不丢审阅输入。
- 不建立新通用组件库，不引入依赖，不改全局导航/菜单样式。

## 验收

- 入口、发布/重试禁用条件、离线反馈管理、保存缓冲区和三方人工审阅保持正确。
- 无项目、已分享、待确认发布、引用阻断、无反馈和有反馈状态可理解。
- 真实浏览器检查浅色/深色、标准/窄尺寸和长路径，内容不横向溢出，底部操作可点击。
- Tab 焦点闭环/Escape 关闭有效；焦点可见，导航 aria-current 与内容一致。
- 相关组件与分享测试、类型检查通过；独立复核后精确提交，不夹带原有改动。
