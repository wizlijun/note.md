# HABITAT 概念准入与关系提取

用户目标：每座建筑对应一个有依据的概念，强度体现知识生长；默认主城只呈现知识概念与明确项目。人名、工具、书名、一般实体和待确认词项在背景层单独查看。本轮仅本地开发与真实数据预览，不发布。

## 问题与边界

旧 habitat-focus/3 把候选统一投影为 keyword，历史词典匹配又绕过近期筛选；结构字段、英文虚词和操作场景中的实体因此进入概念城。冻结样本有 1202 个 keyword、2521 条边，其中 2082 条为统计共现（82.6%）。排序和社区发现不能解决候选语义质量。

运行时仍为本地 Rust 确定性流程，无大模型调用和在线模型下载。采用可审计的术语统计与保守关系模式，不声称实现训练型 NER、AutoPhrase 或通用 OpenIE。规则对复杂隐含概念、歧义实体与转述关系召回有限。

## 流水线

1. 使用既有来源与时间识别：本人主动笔记、本人会话和提交材料分开；最近关注窗口 30 天，按内容时间而非文件修改时间。复制记录按事件身份去重。
2. 从可信正文抽取分词名词及相邻名词短语，合并已有显式词项和完整定义端点。代码、路径、元数据字段、格式指令不产生概念关注。历史词典与近期候选必须经过同一个准入模块。
3. C-value 对嵌套多词术语作统计校正。令 L 为分词 token 数，f 为同一语料中出现的去重事件数，T 为包含该短语的较长候选：C(a)=log2(L(a))×[f(a)−mean(f(b), b∈T)]；T 为空时减项为零。事件频次是针对个人 Vault 的适配，非原论文 raw count。单 token 的 log2 值为零，因此用独立语境通道评估，不能据此删除“记忆”等概念。统计量辅助候选质量/排序，不等于语义类型。
4. 结合可回源的局部概念讨论、完整术语使用、显式项目来源、人物/工具/书名上下文，保留 keyword、project、person、tool、resource、entity、term_candidate 类型。keyword 为兼容既有身份的概念编码；不利用 intentStatus 承载类型。不能仅因提到项目便声称持续投入。
5. 既有近期关注综合主动记录、重复讨论与内容时间；仅概念讨论事件计入概念关注，实体的操作提及留在背景层。全文高频不等于近期重点。
6. 完整句中两端均为准入词项且谓词明确时，提取 is_a、part_of、depends_on、alias_of。subject/object 保留方向；alias 规范化方向仅用于确定性去重。status=asserted 表示原文陈述，不表示客观事实已核验。否定、疑问、条件、推测、引用/转述与不完整混合分句保守跳过；不把“相关”升级为因果。
7. 共现仍为 statistical，保留证据供独立开关查看。主城道路默认使用明确原文陈述或显式链接；统计关联不能默认冒充语义关系。背景节点不参与主城社区命名。Leiden 仅负责对已准入图组织社区。

## 城市、版本与兼容

- 新图主层默认 keyword/project，背景层其余非 topic 类型，另可看全部。背景建筑采用中性展示，不参与概念成熟等级。
- 每个主城节点一座建筑，沿用已有证据成长模型；关联沿道路增宽，不新增跨街区曲线。
- habitat-focus/4 与旧算法显式区分；旧 JSONL/Zstd 与 Git 历史继续可读，算法升级不显示为真实知识重建或成长。
- 节点身份沿用归一化词项 ID；修改类型不重新发明同词身份。完整新快照保留背景信息及证据。验证输出写在工作区审计目录，真实 Vault 不写入。

## 验证计划

- 正反语义样本：完整/嵌套短语、单词概念、人名/工具/书名/项目、格式与代码污染、跨副本重复、不凭弱暗示升项目。
- 关系正反例：四种类型及方向；否定、条件、疑问、转述、多谓词混合、非词边界不得生成肯定关系。
- 冻结 14273 条 manifest 输入与 2026-10-02 /30天/+480 观察日；核对不可读与 hash 不符，不把变化输入冒充同数据对比。重复生成字节一致，审计近期前列和关系原文，明确记录误检与漏检。
- Rust core、插件前端与 backend、旧历史解码/算法不可比回归；主城/背景/全部切换、统计开关、来源详情与真实 WebGL 截图。GPU 重建资源稳定，每个可见对象恰好一个建筑地址。
- 验收不以节点减少等同准确率提高；没有人工标注全量语料，不宣称全库精确率。用实际抽样结论与已知覆盖限制交付。

## 方法依据

- Frantzi / Ananiadou / Mima，C-value/NC-value： https://personalpages.manchester.ac.uk/staff/sophia.ananiadou/IJODL2000.pdf 。只采用 C-value 思路，不声称 NC-value 已实现，也不把英语论文结果外推为中文准确率保证。
- Hearst 1992： https://aclanthology.org/C92-2082/ 。固定词汇句法模式启发；中文以及依赖/组成/别名模式是本地保守扩展，不是原论文的完整算法。

## 实际结果与限制

以相同冻结清单、相同可读来源、相同观察窗口重算旧版与新版，而非使用输入条件不同的旧截图比较。14,273 个来源中成功解析 14,247，26 个因内容变化与冻结摘要不符被排除；观察截止日为 2026-10-02，不代表 10-03 的新增记录已纳入。验证文件位于本地 `tasks/design/habitat-concept-quality/`，不提交用户私有语料。

新图将概念、明确项目与背景分开：158 个概念、2 个明确项目、1040 个背景/待辨认词项，另有 3 个组织主题；已有关系为 303 条 wikilink 与 13 条 imported。近期主城逐项回源复核的是生产力、认知心理学、记忆、AI、情绪、决策、能动性和 Hemory；背景为脚本、写匠、MEMORY。历史分类仍有真实误检，例如操作语境中的 main、图像材料中的主体和 AI录音；未建立全库人工真值，不能宣称所有历史概念准确。局部词性/语境规则不能替代训练型语义理解，同词多义和复杂隐含关系仍受限。

本批未检出满足严格规则的 asserted 关系，保留已有 wikilink 与 imported 候选；这并不表示 Vault 没有语义关系。四类明确陈述通过正反例与端到端定义样例覆盖，真实截图不补造这些边。背景和待辨认词项不参与概念成熟等级；历史说明明确标注为自动识别结果。

旧、新 JSONL/Zstd 均经无损解码重编码复核；跨算法不可作为知识增长比较。相同新快照无节点变化，但因存在未读取来源仍标记为不可比并提示缺失不能视作遗忘。生产 engine 始终提供 focus；无 focus 的直接核心调用是有限历史兼容路径，有无 focus 的结果不应互作增长解释。

界面六种范围（近期/历史 × 主城/背景/全部）实测一节点一主体、标签可见且不交叠、背景无概念成长徽章。近期主城、历史主城、历史背景各 20 次重建和 5 次子集切换验证 GPU 资源稳定，实际鼠标拾取、入口全通、明暗/窄屏及 dispose 重建通过。期间真实浏览器发现并修正密集地块缺入口、短背景标签姓名被徽章压没、稀疏城市聚焦高楼标签出屏三类问题。

产物仅为本地只读预览与源码，没有向实际 Vault 写入新知识版本，没有执行发布、上传或推送。

验证计数：核心 89 项、后端 10 项、前端 68 项及预览服务 4 项通过，Svelte 检查零错误/警告，生产构建通过（保留既有大于 500kB 的 chunk 提示）。新快照与旧 focus/3 共四类 GPU 场景各 20 次重建通过；8/160/1040 个新图地址全部有安全入口。重复解析的 JSONL 与 Zstd 均逐字节一致。
