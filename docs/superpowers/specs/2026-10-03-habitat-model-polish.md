# HABITAT 建模优化

本轮仅优化渲染，不发布。固定34关注词/1202历史词真实快照进行对照。

## 视觉标准

- 近期低密度知识应像精致的小镇/园区，缩短过大的空地；建筑有清楚的地块、庭院、入口与材质层次。
- 密集社区仍按真实成员排布，不增加虚构节点。相同知识ID可对应建筑附属模型，但不能增加显示计数。
- 园区使用有规划的广场、楼群、景观；兴趣营地保留开阔度。道路沿真实网络，联系只改变既有路段等级。
- 维持低模、柔和自然色、稳定阴影、离线模型、实例化批次。

## 迭代与验收

第一轮解决比例/地块，第二轮根据实际截图改园区与景观。每轮保存真实全景/近景并向用户展示。最后验证同数据确定性、建筑/路面不穿插、知识拾取、历史结构兼容、暗色与窄屏以及重复重建无资源泄漏。不以截图代替正确性，也不以测试代替视觉审阅。

## 本轮结果

同一34关注词快照，14地块/34代表建筑全部保留，规划土地面积5445→2991（约-45%）；占地包络5.7%→18.0%。关注分只在近期呈现中影响建筑体量与既有midrise模型选择，不表示掌握程度。1202词历史及32526对象旧图的CityPlan与基线完全一致。

每地址增加有界院落、低围墙和种植，园区用连续台地和内院组织原有四楼，入口步道连接实际街沿。入口步道仅为景观，不写进知识图/边/路宽计算；相同34节点在最近视图形成34入口。沿街树列避让建筑、道路和步道。历史全景地标长标签也参与避让，拥挤时保留可展开标记。

45前端+4服务测试、类型检查和构建通过。真实34关注词、1202历史词和32526旧版对象分别通过20次重建、反复历史标记/过滤恢复、拾取、旋转缩放、暗色窄屏与销毁重建验收，资源稳定，错误/外网资源请求为0；近期56几何/22纹理，历史79/24。标签文案折叠的最后调整另外进行真实UI复验。

全程本地开发，没有发布、上传或写Vault。截图与审计保存在根工作区被忽略的tasks/design/habitat-model-polish目录。后续可继续改进窄屏模型呈现与标签层级；本轮不增加虚构建筑或车流。

最终标签实测：历史全景37个展开标签，矩形相交数0；折叠标记仍可悬停展开。
