# 快捷启动增强插件

## 产品范围
- 插件 ID `notemd.quick-launch`，名称 Quick Launch / 快捷启动，归属 experience。插件菜单打开自有配置窗口，无系统设置贡献。
- 启用插件时显示托盘「启动」子菜单：按保存顺序展示启用且完整的条目，底部「配置快捷启动…」。停用/卸载隐藏整个子菜单。
- 默认 command1（id cmd1）为「屏幕重连」、CLI `uc reconnect`；command2（id cmd2）为空且停用。可添加、删除、更名、启停和上下移动条目。最多20项。command1/2不是键盘快捷键；不注册全局快捷键，不自动执行。
- 条目字段：id、name、kind（app/cli）、target、enabled。应用按名称或绝对路径打开；CLI是用户明确保存的shell命令。首次仅提供默认配置，不执行。
- 配置保存在本机应用配置目录，不写Vault，不跨设备同步。显式保存后立即刷新托盘；运行已保存项，未保存修改不执行。

## 技术契约
- UI-only官方插件，宿主提供 `host.quickLaunch.get` → `{entries}`，`host.quickLaunch.save` 参数 `{entries}` → `{entries}`，`host.quickLaunch.run` 参数 `{id}` → `{ok, ...}`。能力 `quick-launch`，仅官方插件身份可用；原生进程通道不可用。
- 宿主服务为配置与执行的单一来源；拒绝重复/非法id、未知kind、过长配置与启用但空的条目。保存采用原子替换；保存失败不报告成功。读取坏配置报告错误，不回退到可执行默认命令。
- 原生托盘以固定前缀+条目ID绑定，点击时重新确认插件启用并读取当前已保存项，防止旧菜单执行已删/停用项。点击异步执行，同项并发拒绝，保证主线程可响应。
- macOS应用通过 `/usr/bin/open -a` 以独立argv传目标，CLI通过用户shell登录环境执行，以HOME为工作目录并补齐常见CLI PATH；不拼接应用目标为shell代码。其他平台支持范围明确返回错误，不伪报成功。
- CLI有界运行（60秒），连续排空并限制保留stdout/stderr，超时清理进程；退出0才表示命令完成，非0反馈退出码及截断错误。托盘通知持久可查；成功不等于屏幕/远端设备已经响应。
- 插件最低宿主标注下一开发版本门槛；此功能需配套宿主发布。本轮不发布、不安装、不实际运行屏幕重连。

## 验收
1. 隔离配置目录：默认值、持久化、空列表、坏JSON、重复id、空项及保存失败。
2. 执行：无副作用fixture命令成功/非0/超时/大量输出，App参数不经shell；同项防重，禁用与删除拒绝执行。
3. 宿主：能力与身份限制，禁用/卸载托盘隐藏，保存后更新，原生进程通道不可调用。
4. UI：首次默认、添加/修改/删/排序、保存失败保留编辑、运行反馈；类型检查及生产构建。
5. 打包脚本承认新插件，manifest/schema与原有托盘回归通过，双语未发布日志，精确Git提交。
