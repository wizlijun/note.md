# Safari式首页布局

2026-11-19 用户最新明确要求，覆盖旧创建入口与Apps分离、文档默认4行。AI区只确定布局、不接建议内容。仅本地实现/验证/提交，未授权发布。

## 排列

紧凑note.md标识及版本 → 常用功能两排 → 文档两列 → AI建议布局区 → 状态与设置。统一内容宽度和左边界，Safari式轻分区，不增加装饰背景、渐变或高对比大色块；兼顾明暗、墨水屏、键盘、窄窗口。

## 常用功能

桌面两排6列共12位：前三位新建笔记/新建画布/打开文件，接现有8个应用逻辑位（固定优先、剩余按常用），最后“全部应用”。默认功能与应用同图标/字号/间距；创建入口不再单列。保留8个逻辑应用槽及现有home-apps.json，旧固定关系不删、不迁移丢失。空位置在非编辑态保留布局但不制造8个醒目加号，编辑态可明确选择/固定；无历史不伪造常用。固定/移动/禁用/卸载、目录/详情、真实调用和失败恢复沿现流程，菜单复用全局menu-panel/menu-row。

窄桌面窗口仍两排6列，图标缩至40px，文字最多两行截断，点击目标不重叠；iOS保留创建入口的已有边界，不调用桌面插件。

## 文档

两列“新内容”“继续阅读”，每列默认3项；标题右方Show All/全部显示（仅超过3时出现），展开该列全部符合资格内容，可收起，不影响另列。每项保留打开与独立×、标题/日期，新增真实正文预览1–2行。宽窗口并排，窄窗口上下排列。之前的已读/持续阅读/真实编辑/隐藏/原始历史/菜单10项均不改。

ContentCandidate新增可选preview:string|null以匹配Rust序列化，HomeContentItem映射后为可选preview:string。Rust home_content_catalog沿用16KB前缀有界读取Markdown，解析前缀完整frontmatter后取正文纯文本预览，去掉明显标记/重复标题/控制文件信息，不运行Markdown/HTML、不加载远程图片；最终预览截短约180字符。非可安全预览类型不给假正文，UI用文档类型/路径简洁兜底。外部文档无目录元数据时明确兜底，不为首页扫描Vault外目录。不增加全文索引依赖，不把预览写入正文或持久化活动记录。

## AI与底部

AI建议区在文档之后，此次只展示区域标题和诚实的空态占位“建议将在这里显示”，不自动调用LLM、不生成虚构建议、不放未接通按钮。

最底状态与设置保持Vault名称、文档数/内容大小，路径与管理等仍可展开；改轻量footer而非大卡片。全部设置入口同行可见。扫描/保存错误不因收起而隐藏，未配置Vault保留既有引导入口。VaultOverview可新增compact可选属性，默认false保护其他消费者。

## 分工与验证

HomeApps子任务只负责HomeApps组件/样式与其测试；文档子任务只负责HomeContent/model/预览后端及相关测试；主代理负责EmptyState、VaultOverview、AI布局、四语集中新增文案和整体验收。跨文件契约如上。

验证：两排12个位置和前三默认入口/旧固定保留、目录与编辑/hover、3/4边界与两列独立Show All/×、预览来自真实读取且无frontmatter/XSS/超长边界、AI无网络请求、底部折叠/错误、宽窄明暗/键盘/长标题。隔离fixture，不访问正式Vault。前端定向及全量、类型、build；后端扫描实际源码专项和Tauri宏metadata（完整宿主构建若资源仍受限如实记录）。
