# Sumi macOS / Linux 体验对齐

> 2026-11-12 名称纠正：此前文中的 Faitc5 为误拼；当前输入法正式名统一为 Fcitx5 for Sumi，覆盖旧名称保留指令。历史发行证据原样保留。

基线：main eff8c327，正式macOS宿主6.1110.8、Sumi0.1.13；2026-11-11本机版本已核对。用户要求先列清单再逐项解决，非默认跨平台算法重写。

|编号|项目|已核实的差异或缺口|完成标准|
|---|---|---|---|
|P1|回车后上方所有行完全消失|旧mac修复已在正式tag；现有Return测试仅特定字体尺寸做像素检查，发布相关复跑是0项像素检查；用户明确是所有上方行完全不可见，当前复现尚待定位|上文行存在且范围连续；全部可用预设字体/字号、空行/段中/IME提交/连续Return/导航复打检查可见字形及真实窗口；不以alpha属性代替可见文字|
|P2|首次进入聚焦|mac固定首键2秒窗，Linux滑动2秒窗|相同输入时间序列相同激活，读取首键恢复和10秒停顿保持|
|P3|失败草稿声音|mac不可编辑/失败仍有typing owner，Linux停止|冻结即Stop，孤立keyup不响，保存恢复后正常|
|P4|快捷键声音|mac Cmd/Ctrl普通键可响，Linux不响|快捷键不冒充正文打字，Shift/Option正常输入与修饰键反馈保留|
|P5|全屏字号|Linux全屏整体有效字号1–1.25倍并退出恢复；mac无此处理|两端采用同一有界算法，持久偏好不变，退出与异步resize正确，IME期间不破坏预编辑|
|P6|底部额外留白|mac聚焦中心/边缘以全部高度，Linux扣除bottom_inset|有留白时正文有效视区中心一致，候选/光标跟随；默认0不变|
|P7|聚焦候选下方正文|mac展示位移留白，Linux覆盖候选范围|按共规确保当前行不动、不重叠、最多4行、候选关闭恢复；平台绘制机制无需相同|
|P8|正式候选链路证据|桥与布局回归已有，正式host+IME物理GUI未完整验|隔离稿中文预编辑/选词一次提交，搜索退出接管，正常保存重开；不修改正式写作稿|
|P9|Linux硬换行|mac insertLineBreak发送hard_break，Linux无明确ShiftReturn映射|检查既有契约与测试后补Linux一致快捷键；本机无法做Linux GUI则明确记录|

|P10|本机编辑同步回送阻塞设置|完整隔离宿主复现相同op_id本地revision3/远端echo revision4，receipt摘要冲突阻塞SetPreferences|同一CRDT更新的回声幂等，真正不同payload继续拒绝；旧pending日志可恢复；实际字体/外观应用通过|

已对齐：非聚焦输入位置保持、预编辑无蓝底、剪切先写剪贴板、Edit revision严格增长、草稿保留/Save重试、设置面板菜单、原生无滚动条。Linux Pulse运行目录、GTK窗口CSD/命中层、Cmd与Ctrl/F11映射是必要平台区别，不照搬AppKit。

实现只改确认缺口；像素故障先复现再修，不用全量cache失效掩盖。先跑独立原生回归再真实窗口观察，所有输入仅合成稿。当前工作区searchidx/store.rs与smart_lookup.rs为其他任务，禁止夹带。代码提交与正式发布证据分开；原生改动需要宿主重新构建，插件升级本身不能交付。

附加任务：Faitc5新增中英文边界自动空格、默认开且可关闭，用户确认示例你好hello世界→你好 hello 世界；在输入法仓库单独设计，不能误用候选间距或半角标点选项。
