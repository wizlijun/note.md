# HABITAT 游戏级城市渲染

## 目标与验收

用户多次指出方块与规则街区过于简陋。本次是展示引擎重构：以成熟浏览器城市游戏的模型和场景组织方式实现可探索的知识城市。知识提取、稳定身份、快照和 Git 历史协议保持原语义；关系只改变街道等级，不画跨区连接弧线。

真实 32,526 对象快照的首屏须呈现连续不规则城市；近景能辨住宅屋顶、门窗、庭院、商业建筑立面、路肩与设施。Hemory/note.md 用有庭院的完整园区，Bushcraft 用森林营地；未归属材料采用低矮建筑/施工材料的成长区。装饰不被计为知识对象或真实调用事件。

- https://github.com/lo-th/3d.city ：借鉴街区密度、环境调色、集中模型资源；实际 LICENSE/COPYING 与 README 存在授权描述差异，不复制其代码或模型。
- https://kenney.nl/assets/city-kit-suburban （2.0）、https://kenney.nl/assets/city-kit-commercial （2.1）、https://kenney.nl/assets/nature-kit 、https://kenney.nl/assets/survival-kit ：官方 CC0 游戏模型，选取必要 GLB 与纹理随插件离线分发，保留下载 URL、ZIP hash、文件清单与许可证。

## 模块契约

1. `city-plan.ts`：纯确定性布局。原 8 单位格只用于空间聚合，显示层用抖动中心 Voronoi 地块。道路沿地块边界，住宅沿道路朝向布置，园区预留较大占地。返回地块、多段道路、代表建筑与全部节点到可视位置的映射。输入重排不改变输出；edge 增加不改变道路骨架或摆楼位置。
2. `city-assets.ts`：GLTF 本地加载、尺寸归一化、几何/材质缓存及 InstancedMesh 合批。实例保留知识 node ID。缓存只在最终 dispose 释放；快照切换释放实例及临时场景。
3. `city-scene.ts`：地形/水岸、连续街区地面、模型组合、路面等级/路肩/标线、植被、光照/接触阴影、镜头与选择。公开 Svelte 接口保持兼容。异步加载带代次保护，错误可见；全部节点仍可通过列表定位。

## 视觉设计

- 色彩：温暖石色道路边缘、深灰路面、自然植被、蓝绿色水体；模型保留统一的游戏资产材质。
- 布局：不再显示规则圆盘，地块填充为连续草地/庭院/材料地；园区中心广场、林间帐篷与滨水步道提供留白。
- 模型：住宅多变体；园区高低配楼和中庭；成长区仓棚/低层建筑与木材；树木混合轮廓，沿道路保持净空。
- 道路：同一网络承载关系强度。固定权重与固定单调路宽，增加路肩与标线使高级道路明确可见。没有调用记录时不生成声称真实的车流。
- 渲染：实例化模型、合并静态路面，稳定光照与软阴影/接触阴影，按需渲染；控制资源、绘制次数和 GPU 内存。

## 验证闭环

- 单测：乱序确定性、节点覆盖、路宽单调/骨架不变、实际占地碰撞、空/小输入、资产服务白名单。
- 自动浏览器：真实快照全景/住宅近景/两个园区/营地/成长区/深色/800px，模型请求全部成功；离线资源、搜索/选择、连续快照重建后身份和资源稳定。
- 记录 renderer draw calls/triangles、首屏成景时间及旋转帧时间，避免只按“页面能打开”验收。
- 逐轮看图并独立审阅。未达到模型、规划和画面层次门槛则继续修正，不把一次测试通过当成视觉完成。
- 沿用现有 Wrangler 3 签名发布流程；只有通过上述验证后才生成新版本包。

## 实施验收记录

三轮真实数据画面校正完成：替换模型、收紧自然边界与沿街密度、修正地形盖板遮挡、改进散列分布以消除植被条纹、补完整帐篷篷布。34个GLB/3张PNG全离线；110地块/347路段/350代表建筑覆盖32,526对象。保留投影转换，删除已退休的网格街区/旧路由实现及其测试，由新规划测试覆盖确定性、道路等级、节点完整性和碰撞。
