# NEXT 完成并记一笔

## 交互

在身份有效且处于 capture、wip、waiting 的 Task 安放菜单首项提供“完成并记一笔”。沿用“接下来怎么办”弹窗，预选完成；只突出“一句话补充”多行输入，支持粘贴，不要求填写其他字段。输入自动聚焦，空内容不能提交，主按钮为“完成”。取消不写文件。原快捷完成、更多、Idea 和已安放状态入口不变；不自动重开 dormant/closed。

## 保存契约

记录只追加到 Task 源 Markdown，保留既有正文、YAML、UUID和换行格式。使用同一完成事件 ID 标识追加记录，含时间、完整补充文本及不可见的起止标记；账本不重复保存正文。保存前重新读取工作区并用统一 validateAppend 校验状态与身份。源文件回读确认后才用既有 appendEvent 追加完成事件。成功后关闭弹窗、播放礼花，并调用既有无模型 skills 同步入口；外部同步失败独立提示。

保存期间禁用重复提交。任一阶段失败保留同一操作、输入和事件 ID，并锁定输入供重试；检查完整记录而非只检查标记，避免应答丢失重复写入。部分成功时提示记录已保存但完成仍待重试。当前表单关闭或应用重启后不自动恢复未结束操作；已写入记录保留。文件改动、UUID替换/重复、并发结束状态须拒绝，不能覆盖源文本或隐式重开。现有 Vault API 无跨设备 CAS，不能承诺跨设备原子事务。

## 验收

隔离 Vault 覆盖多行粘贴、取消/空输入、原文保留、完成事件及脚本顺序、源文件与账本写失败/应答丢失、固定操作重试、记录冲突及身份变更。实际签名包验证相同交互和旧快捷完成；菜单复用全局 menu-panel/menu-row，并检查真实浏览器 hover。不得修改正式任务或发送真实提醒。最低宿主保持 6.1027.1；本轮仅发布插件 1.10.0。
