# Garmin 官方导出 ZIP：真实数据调试验收

本次实现官方导出 ZIP 的离线预览、导入和查询；没有修改正式 Vault、Keychain 或当前 API 账号。**源码开发版，尚未发布；市场 0.1.2 不包含此功能。** 原始下载链接、个人身份和健康读数未放入受控代码或本报告。

## 行为

- 独立窗口入口和 `health-garmin-import ZIP --region china|global` 命令；区域必选，Apple/API 原有参数含义保持。
- 按 JSON 内容识别，兼容本地化文件名、活动包装数组、字符串与毫秒日期、对象 UUID、缺少步数的日统计、嵌套午睡和生物指标日期。
- 使用与 API 相同的区域/profile 账号身份；交叉核对 profile 字段及活动 ownerId，混合身份拒绝。离线账号可从数据查询筛选，无需凭据或改变当前账号。
- ZIP 使用独立 `export_*` 集合。分卷累积，稳定 ID 更新可跨日期，没有稳定 ID 时按内容去重；未出现记录、API 和其他账号数据保留。覆盖为实际观察到的 `observed`，不推进 API 游标、不宣称全天完整。
- 全部原始成员逐字节保存；未知 JSON、无扩展名图片、嵌套 ZIP/FIT/备份均保留。FIT 未解析为逐点读数，无可靠日期的记录保留为 `_undated`。
- 路径、重复成员、符号链接、CRC、JSON、身份、附件校验和均有提交前检查。额外核对物理 central-directory 条目数，防止 zip 2.x 按名称索引静默折叠重复成员。

## 真实样本

官方包含 185 条 ZIP entries：180 个文件、5 个目录，其中 171 个 JSON、5 个嵌套 ZIP。外包和内包 CRC 正常；嵌套包包含 18,900 个 FIT 与 1 个 BAK，按原件保留，未将其计为已解析读数。

从 149 个 JSON 解析 19,263 条输入记录，22 个健康集合去重后为 19,094 条；另有 180 条原文件元数据，归档合计 19,274 条。其余 31 个文件仅保留原件；部分已解析 JSON 的未知成员也仍在原文件中。180 份原件的每个成员字节均与 ZIP 一致，相同内容共用 179 个附件对象。

已解析 JSON 日期范围为 2022-07-31 至 2026-01-09，不据此推断未解析 FIT 的日期。关键数量：活动 466、睡眠 1,173、午睡 160、每日汇总 1,221、生物指标 240。全部 22 集合均由独立 Python oracle 按官方文件类别提取，并与归档逐 canonical payload 和日期核对；该脚本没有调用生产解析函数。

| 实际 CLI 流程 | 秒 | 结果 |
| --- | ---: | --- |
| 空隔离 Vault 预览 | 25.556 | rc=0，Vault 无文件写入 |
| 首次隔离导入 | 151.340 | rc=0，13,311 个归档文件 |
| 重复同包导入 | 31.741 | rc=0，全部文件内容、大小和 mtime 不变 |

上述为本机 debug 构建单次测量，不是性能承诺。真实运行禁止网络，状态目录仅有写锁；原 ZIP 哈希保持。

## 实样发现的浮点问题

首次独立核对发现 999 条记录中的 11,413 个浮点字段发生 1 ULP 偏差，涉及 7 个集合；没有接受“数量一致”或放宽浮点容差作为通过依据。根因是默认 serde_json 浮点解析/再序列化路径。启用 `float_roundtrip`，加入 999 组合成长小数 bit-level/roundtrip 回归，确认旧路径失败后从空隔离 Vault 重跑。最终严格 oracle 通过全部字段，原始附件字节也逐一通过。修复前候选数据和日志明确标记 rejected，未用于最终验收。
