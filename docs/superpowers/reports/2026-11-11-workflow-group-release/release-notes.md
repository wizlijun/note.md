## 安装 / Install

- **Apple 芯片 Mac：** `note.md-6.1111.2-aarch64.dmg`。
- App 与 DMG 均使用 Developer ID 签名、完成 Apple 公证并附票；自动更新适用于 Apple 芯片。
- 附带改造后的 **Faitc5 for Sumi 0.5.0.13** 安装包。其中 App 已签名并公证，`.pkg` 安装包本身未签名。
- 本次未发布 Intel Mac 或 Linux 宿主。

## 变更 / Changes

- 宿主原生菜单和内置插件市场统一为 **AI → 捕捉 → 阅读 → 写作 → 推进 → 回顾 → 数据导入导出 → 其他**。
- 英文分组统一为 **AI → Capture → Read → Write → Advance → Review → Import & Export → Other**。
- Sumi Write／玄霜写作和奇思妙想归入写作，位于阅读后。
- Apple Notes、Roam Research 和健康数据同步归入捕捉，兼容已安装的旧插件清单和缓存分类。
- 旧灵感分类映射为写作；旧 Other 和未知分类归入其他。已知旧分类别名仍映射到对应分组。
- 插件网站已采用同一顺序与名称。插件业务数据、设置及既有词库保持不变。
