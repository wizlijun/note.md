# Sumi 本机写作可靠性修复

状态：实现、代码审查及隔离回归通过；签名产物尚未验收，尚未发布。此报告不包含用户正文、数据库、凭据或恢复副本。

## 问题与行为

已发布版本的宿主分别读取数据库基线与文件，后台正常写出新投影时也可能触发时间文件不一致错误。更严重的是，投影错误会阻止打开已保存在本机的正文；原生输入确认与后台 SQLite 提交之间还存在仅驻留宿主内存的窗口。

修复后，本机 CRDT 正文可在文件投影异常时打开和续写。后台在单一保存作业内返回正文、基线与文件观测；未知外部文件保留待处理，行时间保护不放宽。宿主输入在确认前先写入 SQLite WAL/FULL/fullfsync 日志，后台精确持久回执后才回收，重启先幂等重放再读取。磁盘或队列失败时原生编辑器保留可见草稿、允许 Markdown 复制并暂停修改；重试使用同一操作，不能静默回滚新输入或在未保存时关闭。

导入正文的持久化与覆盖外部文件的许可分别处理。磁盘再次变化不会让已记录的 ImportLocal 永久堵住重启；其原始身份和回执不变，新的外部文件不被覆盖。

## 验证

- 实际已发布 0.1.5 后台与冻结 6.1108.6 校验代码复现旧基线/新文件竞态。这个复现不能单独证明用户现场旧文件的来源。
- 后台全量 104 项、stdio 2 项、旧插件能力握手专项及 write-core 85 项通过。代理集成包含真实 SIGKILL、丢失回执、导入后文件再次变化以及唯一 outbox/精确回执断言。
- 宿主 Sumi 回归 78 项通过，4 项默认忽略：专用崩溃子进程、显式性能采样、需指定真实后台路径的宿主进程测试，以及会写入真实钥匙串的测试；本机文件异常续写、缓存正文刷新、投影状态和草稿重试均覆盖。另显式执行真实后台路径的宿主进程测试，1 项通过。
- 原生 Rust 7 项及 AppKit draft、panel、clipboard、caret、shortcuts、unicode、position 七套离屏探针通过。负 ACK 保留键入、粘贴、剪切、动作与 IME 草稿，ApplyDocument 与宿主解除冻结在同一主线程回合完成。
- 本机日志独立崩溃回归通过。合成中英文 CRDT 更新各 100 次的同步日志实测 p50 约 4.36ms，p95 约 5.25ms；不包含渲染、IPC、日志删除或锁竞争，不代表按键到屏幕端到端延迟。

本轮没有进行物理断电实验。断电耐久性依赖 SQLite FULL 与平台 fullfsync 保证；实际签名宿主/插件包、发布 tag 和公网验签另行记录。聚焦打字、底部状态隐藏及其他未发布工作不属于这个隔离修复分支。
