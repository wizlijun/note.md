# Sumi 首键恢复与回车绘制修正：实现验收

状态：最终实现与真实屏幕验收通过，可开始构建；**安装包与公开发布仍待完成**。实现已提交 `f20d5797f7b87591b9e8c78abeaffa7348c85370`，本报告不证明目标宿主6.1110.1／插件0.1.10已进入安装包或市场。

阅读导航后首个输入立即恢复聚焦，包括异步中文预编辑与提交；嵌套keyDown只计一次。空marked取消、unmark及面板清理只刷新几何，不重置打字空闲计时。保留初次普通旧稿四键、空页首行居中，以及只读、隐藏、草稿错误与IME保护。冻结基线首键/拼音两例均失败，最终输入回归117项通过。

回车规范投影后，TextKit邻段细化曾使旧/新fragment坐标重叠。最终实现先准备有界候选、提交viewport，再丢弃旧行对象并读取同轮可用快照；不伪造行坐标，不改字体、行距和衰减常量。原生layout使用既有主队列合并刷新，避免同步重入。仅延后刷新仍在较长真实输入序列中丢失中间字形，因此不能把它单独列为屏幕问题的修复。

最终绘制改为缓存当前视区的不可变原生字形图像，窗口只合成图像及透明度；NSTextView继续拥有编辑、选区、IME与辅助功能。缓存键包含原生段落快照身份和行range，避免相同可见字串在不同上下文误用字形。图像有明确释放路径；没有全文缓存，任一捕获失败便整体回退原生编辑器，退出时恢复原生层透明度。独立源码审查无遗留必须修正项。
