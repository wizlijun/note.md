# Health Sync 0.1.1：真实 Apple 导出兼容验证

本轮继续开发现有 0.1.1，未发布市场版本、未安装插件、未修改正式 Vault。真实 ZIP 仅在本机私有、Git 忽略的测试目录中处理，本文不包含健康记录、指标值或原始附件内容。

## 复现与修复

旧实现按 `export.xml` / `导出.xml` 白名单选择主文档。实际 ZIP 未正确声明文件名编码，主 XML 被解码成乱码，导致导入立即失败。即使识别主文档，约 1.74 GB 的 CDA 附件也超过原有 256 MiB 限额。

- 主文档与附件共用 ZIP 检查，在 `.xml` 文件中（扩展名不区分大小写）按无命名空间的 `HealthData` 根识别唯一主文档，附件按选中索引排除主文档。
- 不依赖文件名语言和所在目录；缺少主文档或存在多个主文档明确失败。
- 最多探测前 1 MiB，支持 BOM、DTD、注释和处理指令。本次导出根节点偏移 7,957 字节。
- CDA 依据 `urn:hl7-org:v3` 命名空间中的 `ClinicalDocument` 根识别，沿用 64 GiB XML 限额；普通附件仍限 256 MiB，附件累计仍限 64 GiB。
- 大附件持续流式读取，保留实读长度、CRC、SHA-256 校验和原始字节，不通过增大内存缓冲处理。

兼容边界：仍要求 XML 扩展名，超过 1 MiB 前导的 XML 成员会明确失败。本轮未扩展 ZIP 库已有的同名目录项去重行为。
