# NEXT 1.9.0 发布验收

2026-10-27 已发布 `notemd.next@1.9.0`。本版包含项目/Idea/Task/搜索筛选与“显示已安放”的独立控制、同步失败原因提示，以及多行脚本环境变量设置界面。

**本次仅发布插件。** 最低宿主保持 `>=6.1027.1`。当前已发布的 6.1027.1 可继续选择和执行原有脚本、使用筛选修复；环境变量输入显示升级提示，具体失败码也需要配套宿主更新。`host.taskHook.setEnvironment` 的宿主实现虽已提交，尚未进入本次宿主安装包，不能将插件发布视为该能力已部署。
