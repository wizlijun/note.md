# Oura 真实 DSR 导出导入与解析验收

2026-10-30 使用用户提供的 `ouraring20261024.zip` 完成开发验证。修复前 0.2.0 独立安装包在隔离预览时退出 1，错误为 `Invalid Oura export CSV record`；修复后实际独立 CLI 的预览、导入、重复、状态、目录及查询均退出 0。当前改动尚未发布或安装到正式应用，正式资料库未修改。

## 修复范围

- 实际 DSR 使用分号 CSV。自动区分分号/逗号，支持 BOM、引号内标点、跨行字段、空成员及仅表头文件；按字段识别，不依赖文件名。
- CSV 流式读取，139,428,769 字节的位置成员不再被旧 64 MiB 成员限制阻断；保留 4 GiB 总量、路径、实际长度和 ZIP CRC 检查，JSON 仍限 64 MiB。
- 补齐 15 类健康/传感器字段识别，包括体温、步数、动作、日间压力、外部心率/步数、心血管细节及平滑年龄、VO₂ 估计、活动预测、运动心率会话、时区、餐食和心肺活动基线；平滑年龄与原始年龄分开。
- CSV 原始字符串、精度表示、嵌套 JSON 单元格和未知字段保持原值。新增无 ID 传感器按完整内容识别，既有 V2 身份逻辑不改。账号、离线集合和 API 游标维持隔离。
- `file_reports` 返回每个成员的解析/未知计数及状态。原件保留列表包含未解析 CSV 及其他文件；整份 ZIP 作为单个附件保存，不把原始明细写入 Vault。
