# NEXT 1.11.0 发布验收

2026-10-27 已发布 `notemd.next@1.11.0`。Task 卡片提供“帮我开个头”的选择、结果问答与安放流程，Agent 列表动态来自用户已安装的插件，包含仅 Codex、仅 DeepSeek 和无插件的情况，不固定 Claude Code。人工答案独立保存，安放仍由用户确认。

**真实模型安全验收按用户要求留待后续，当前所有 Agent 的开头执行入口保持禁用。** 已有结果可查看、回答和安放。本次只发布 NEXT universal 插件，不部署配套 Agent 后端或宿主，不在本机安装，不操作正式 Vault 或发送提醒。
