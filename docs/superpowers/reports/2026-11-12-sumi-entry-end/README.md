# Sumi 进入时定位正文末尾

Sumi 独立窗口新建原生编辑面时，把折叠光标和初始视口设为渲染正文的 UTF-16 末尾。覆盖冷启动、关闭后重新进入和新打开纸页；正文末尾有换行时位于最后空行。主编辑器仍恢复持久阅读位置；已存在编辑面的普通聚焦、设置返回及重绑不会重置光标或打断组字。

Linux 显示回归发现原 viewport 恢复在 scroll_to_iter 后无条件写回旧 adjustment，零偏移也会取消 GTK 延迟滚动。修复后零偏移不写回旧值，末行可见。非零阅读偏移逻辑未扩大修改。

验证：宿主 Sumi 36 项通过，覆盖空正文、中文/emoji、Markdown 渲染末尾、非零阅读位置保留及正文/修订不变；原生单测 35 项通过。隔离 Wayland 和 Fcitx GTK 显示测试分别通过，150 行长文首次及重挂均在末尾且可见，输入追加末尾，末尾换行有效，设置返回保留手动选择的开头。新增显示测试修改前失败（光标 y=5286，落在视口之外），修复后通过。Wayland 输入法音效专项再次通过。
