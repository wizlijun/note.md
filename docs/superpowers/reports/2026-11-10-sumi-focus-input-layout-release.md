# Sumi 首键恢复与回车绘制修正：macOS 发布

宿主 **6.1110.1** 与 **Sumi 0.1.10** 已公开，仅 macOS Apple Silicon。请配套更新，插件最低宿主为 `>=6.1110.1`。宿主冻结tag为 `v6.1110.1`／`ecc9fb4298c2c271601fd345e15f17c1410aa56c`，准备源码为 `183b636b05bcf1440e2b8626f28629ce44b78863`；输入与绘制修正分别见 `232dbe14`、`f20d5797`。[下载宿主](https://github.com/wizlijun/note.md/releases/tag/v6.1110.1)，插件通过现有市场更新。

移动光标或滚动阅读后的首个真实输入立即回到聚焦行，包含异步拼音预编辑；方向导航仍不刷新打字停顿时钟。回车后从同轮有效TextKit快照定位上下文，保留字号、行距与既有渐隐层次。聚焦绘制使用当前视区的不可变原生行字形缓存，避免真实窗口重绘时裁切或缺字；输入、选区与IME仍由NSTextView拥有，缓存失败整体返回可读原生界面。保存、CRDT、行时间与本机持久日志未改。

最终源码117项输入、49552项布局／560次规范回执／20项位图、3932项原聚焦、56项缓存与原生10组回归通过；最终源码构建的真实窗口三轮缺字序列及空白首行／首字／回车均完整居中。宿主正式流程427套5551项前端测试通过，插件UI101项通过。实际签名插件的stdio 2项、崩溃重放13项与宿主代理1项通过。实现验收及保留的旧阶段失败见[实现报告](2026-11-10-sumi-focus-input-layout-validation.md)。物理输入法候选窗口未验，预编辑／提交／取消与候选定位回调已覆盖。
