# Pele 全图形主题样式修复验证

日期：2026-10-19。基线 main `95ffbe213162cc3c52badf80f1ffe280c731049c`，Pele 1.6.0，CORE `03225cad14863d1b67113601fd994c87055d724f`。本报告对应同一提交内的修复，尚未发版；公开 v6.1019.1 安装包没有因此改变。

## 修复与边界

- 精确接纳 title / heading / bold 三种原生字重变量，并在 SVG 根冻结可信字重，保留原来被整段删除的根样式。外部资源、未知变量和主动内容限制保持。
- 普通节点与分组改用 secondary / tertiary 表面色，强调色独立；八个系列使用分类色，避免把 UI 背景作为第二、第三条统计线或反色标签底色。
- Pele 桌面、静态导出和分享使用明暗主题默认值。没有旧 CSS 变量的深色页面不再回退到深色文字或浅色节点背景。主题覆盖值仍被尊重，不保证任意自定义颜色的对比度。
- 旧 Mermaid 保持默认主题读取行为、实现和独立图形资源字节不变；不增加设置项，不改变构建开关。
- [图谱](../../examples/mermaid-pele-theme-gallery.md)全部 50 个图形源码逐字保持，覆盖 33 个注册类型及主要变体；更新了当前映射和历史缺陷说明。

## 验收限制

50 图均检查明暗概览，重点图另查实际 NodeView 和独立输出。大图在 360px 或概览内等比缩小时文字自然很小，不能据此承诺 96 节点在手机宽度下同时清晰可读；需放大或宽窗口查看。D02 / F02 的显式颜色是固定对照，不要求自动随主题变色。原生 WebView、系统剪贴板和实际 PDF 未在本次实机验收；独立 SVG / Chromium PNG 不替代这些检查。旧 Mermaid 两套各 48/50 的解析结果沿用图谱，不把它们写成旧引擎视觉验收。
