# Vault 入口、首次引导与欢迎页概况验证

日期：2026-11-14。按同日确认 spec 实现。状态：本地源码实现与验证，未发布、未安装替换用户应用。

## 实现范围

- 文件菜单和托盘共用一个状态化 Vault 项；未配置进入引导，已配置只进入设置。主窗口隐藏/重建时使用可消费的待处理请求，避免丢失菜单操作。
- 首次可见的桌面 GUI 引导支持创建、已有目录、跳过及完成页；后台 CLI 不触发，CLI 安装提示推迟到后续启动。
- 桌面设置 Vault 页：路径、Git 初始化、真实同步状态与控制、文件收集配置；更改位置仅在折叠高级区，确认列出原/目标路径，默认焦点取消。未保存文档沿既有保存/放弃/取消流程。
- 新根默认暂停同步；Git 初始化不 add/commit/push。每设备每根授权，旧配置仅按既有仓库迁移。切换串行化并等待旧 worker 结束，配置两份写入可回滚，失败不发布新根。
- 欢迎页展示当前根、文档数、内容逻辑大小；独立元数据扫描，排除 Git/管理数据，不跟随符号链接，不读取正文。提供取消、同根内存快照、失效与部分统计状态。
- 路径显示使用 `~`，复制完整路径；新增文案包含中、英、日、德四种语言。iOS 原流程保持。

## 界面验证

在 Chromium 中挂载实际 Svelte 组件，使用隔离 IPC fixture；没有连接真实 Tauri 后端。检查了首次引导创建到完成、跳过后重新进入、Escape、位置变更确认与取消、默认取消焦点、欢迎页浅色/深色，以及 600×400 窗口无横向溢出。页面无脚本错误。

初轮发现位置确认框在 busy 期间尝试聚焦禁用按钮，导致焦点停在容器；已改为 busy 结束后聚焦取消，真实浏览器和组件回归均通过。
