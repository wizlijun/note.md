# HABITAT 关键词网络与近期关注

当前算法为 `habitat-focus/5`，快照使用 `vault-knowledge-structure/2`，兼容读取 `/1`。历史基础图延续 v2 的关键词投影与 Leiden；近期层另外从可信、可定日的本人正文提取词项，不把历史 PageRank 当作近期注意力。关键词没有覆盖所有正文术语，缺边表示当前证据不足，不能据此判断两个词毫无关系。

以下“词项与关注线索”至“社区与历史”描述历史基础图；“近期关注层”单独定义默认前景。

## 词项与关注线索

- 排除 document/topic；NFKC、空白和大小写规范化，相同拼写沿用 `keyword:<normalized>` 身份，但保留概念、明确项目、人物、工具、资料、实体或待辨认类型。这是词项身份，**不证明同名人物或实体是同一对象**。
- 证据、原文定位、来源状态和项目意图全部保留；别名仅用于显示/检索，不作传递式身份合并。
- 过滤纯数字、日期、明显代码/配置标记、工作流来源标签和过长句子。没有主题白名单。
- 关注候选需至少一组 human 正文上下文证据、两组明确链接证据、明确项目声明，或两组未标明作者的原生来源并具有链接上下文。页面自身的 human metadata 不当作本人讨论了这个词。
- 导入词不获个性化跳转初始权重；只有至少两组来源、与原生关注词存在明确关联时才参与入选，至多 120 个。总关键词上限 1,200，候选不足时不补满。

令 `F` 为全部去重来源组数，`df(t)` 为包含词项的来源组数：

```
idf(t) = ln((1 + F) / (1 + df(t))) + 1
TF(t) = 1 + ln(1 + df(t))
attention(t) = 4 ln(1 + humanContextGroups)
             + 1.5 ln(1 + linkedGroups)
             + 0.3 ln(1 + unknownNativeGroups)
             + 2 * declaredProject
prior(t) = idf(t) * TF(t) * attention(t)
rank(t) = .55 * normalized(prior(t)) + .45 * personalizedPageRank(t)
```

PageRank 阻尼 .85，固定排序，100 次迭代上限、L1 差小于 1e-10 收敛。每词每来源组对 TF 最多贡献一次；重复拷贝、同源迁移段落不会增加词频。关注度是来源线索，不是对本人心理状态的断言。

## 明确关系与统计关联

明确关系按 `type + status + 规范化词项参与者及角色` 先聚合证据，再重算来源组。相同来源组的重复声明不额外增加 PageRank/Leiden 权重。二元关系聚类权重为 `authority * ln(1 + min(16, sourceGroups))`，observed/user-confirmed/asserted 权威系数 1，imported 为 .25，candidate 为 0。asserted 只表示原文陈述，不代表已核实的事实。超边保留全部角色和状态，不展开为事实完全图。

统计关联只用 `verification=matched`、`role=context` 的 paragraph/outline_node：

1. 每个窗口最多 12 行、8 个候选词；先按 **source ID + locator** 还原真实段落。相同来源家族内不同文件的同一行号，绝不能拼成一个段落。
2. 再按 **source family + 关键词集合** 保守去重；不同位置的同组词转抄不会制造额外样本。这里不声称原文内容相同。
3. 所有边际概率、联合概率都在上述同一套窗口样本上计算。`NPMI = ln(p(a,b)/(p(a)p(b))) / -ln(p(a,b))`。
4. 保留在至少两组来源中共同出现且 NPMI≥.05 的词对，聚类权重为 `NPMI * sourceGroups/(sourceGroups+2)`。若所有窗口都包含这对词，0/0 不擅自解释为满分相关。
5. 输出 `edgeType=co_occurs,status=statistical`，只表示共现，不能变成因果/支持等语义断言。统计边进入社区图时另乘 .1；背景节点不参与主城社区组织。

明确原文关系使用有界句法模式：is_a、part_of、depends_on、alias_of、influences。影响陈述保留 subject/object 方向和完整原句；同日同命题去重。一个提问回合可以包含独立陈述，但假设、引用、求证、否定和问题的作用范围仍被保护；不跨句补主语、不从共现推断因果。默认城市只呈现明确陈述和显式链接，统计关联需单独打开，导入候选保留在详情。

未知谱系的 distinct family 仅称“去重来源组”，不是已知独立来源。`verifiedFamilies/provisionalFamilies/unresolvedLineage` 按原来源状态分开计数；即使 family verified，也只说明来源家族解析成功，不证明关系内容为真。

## 社区与历史

使用 **leiden-rs 0.8.1** 的标准局部移动、细化、聚合三阶段，禁用默认并行特性，Modularity resolution=1，seed=42，skip_refinement=false。孤立词保留，不生成关系或强行归入社区。社区名称取内部强度平方/总强度最高的 2–3 个词。

关键词身份稳定；社区沿用 Jaccard≥.6 且领先第二候选≥.15 的一对一续接，保留拆分/重组谱系。新社区以出生 ID 作为匹配键。算法迁移明确标记 `changeCause=algorithm`，不能把方法变化说成知识增长。

布局按真实 primary membership 分配，迁移时不继承旧空间分桶。仍存在的社区保留中心，同社区关键词保留坐标，跨社区词重新落位，pinned 位置优先。社区按成员规模预留空间。

## 近期关注层

`FocusContext` 显式保存 `asOf`、`windowDays` 和 `utcOffsetMinutes`。默认窗口 30 天，为 `[asOf-(windowDays-1), asOf]` 闭区间；没有日期、未来日期和窗口外材料不贡献近期分数。日期冻结后同输入可复现。RFC3339 时间转换到冻结时区，导出会话中的无时区 Started 日期按原记录当地日期使用，不擅自解释为 UTC。

可信来源是 Agent 导出中真实 `## 👤 User` 段、明确 `by:: human` / `human:me` 的原生大纲单元，以及明确本人提交的 Trace Request。排除助手/工具段、fenced 示例伪角色、skill/AGENTS/子代理/自动审批与其他已识别包装、问题回显、诊断日志、敏感配置和纯执行短句。索引器默认 `origin=human` 不足以证明本人主动表达。跨日长会话没有逐条日期时，仅首个 User 段可以归于 Started；后续段保守排除，故覆盖不完整。原生 Daily Note 使用所属日（`daily_date`），其他原生记录要求明确创建日期；Trace Request 的文章属于 `submitted_material` 低权背景，不等于本人信念或亲自写作。

事件身份使用会话 Started 完整值、Project、Source 和规范化 User 正文；重复导出只算一次，不同日期真正重问保留为再访。同日每词贡献封顶。一般文本没有可靠谱系标识时不能证明跨会话改写或转抄是独立原创，分数不是独立证据数量。

候选由 Jieba 名词/名词短语、既有词项的实际字面命中和明确关系端点获得。明确领域枚举或能力目标中的词项允许有界的动词名词化；不普遍放开动词短语。词项必须是连续原文字面，英文保留词界，中文避免把完整长词后缀当独立概念。每个事件每词选有实质概念语境的最强局部句，保存原路径与行号，不只取第一次字面出现。

近期和历史共用术语准入、按去重事件频次适配的 C-value 嵌套校正及局部概念语境判定。全语料重分类后重新筛选事件、日期和分数，不把背景分数直接改标签充作概念关注。概念/背景仍为规则分类，可能误分；明确项目保留 project 身份，在主城独立展示。代码、格式、操作指令、转抄材料不能凭高频冒充概念投入。背景的使用证据保留在历史图中。

令 D(t) 和 E(t) 为最终通过语境门禁的观察日期/事件集合，E 为窗口内去重可信事件数；L 为分词 token 数，f 为去重事件频次，T 为包含该术语的较长候选集合：

```
C(t) = log2(L(t)) * (f(t) - mean[f(b), b in T(t)])
       # 无较长候选时减项为0；单token术语另走语境门禁
A(t) = sum[d in D(t)] 2^(-ageDays(d)/10)
IDF(t) = clamp(ln((1+E)/(1+|E(t)|)), 1, 5)
termhood(t) = L(t)>1 ? 1 + .2*ln(1+max(C(t),0)) : 1
raw(t) = ln(1+A(t)) * (1+ln(1+|D(t)|))
         * sqrt(IDF(t)) * termhood(t) * categoryFactor(t)
score(t) = raw(t) / maximumRawScore
```

categoryFactor 对概念为1，背景为.22。上述是最终重新筛选后的排名，早期候选筛选的词长/询问启发式不再作为最终分数。

10 天指数半衰期、贡献倍率和阈值是可审计的工程选择。时间衰减、重复再访及饱和思想受认知激活模型启发；这里不是忠实的 ACT-R 实现，也没有声称获得科学验证。近期排名不混入基础图的 `.45 PageRank`。归一化分数只用于本次排序，不宜跨版本比较，更不表示百分比掌握程度。

前景最多 30 个概念和 8 个背景，不补齐配额；分数至少 .1，常规项至少跨 2 天；最多 6 个单日概念可以凭明确领域对象、定义对象、实质关系论元或应用能力目标进入；或者沿用至少2个去重事件、2条不同原句、至少4字符的重复讨论通道。单日通道不能继承宽泛的“为什么”操作提问，也不将“甲对乙的重要性”中的受益对象乙自动当研究重点。单日不等于首次出现或持续投入，仍保留实际日期与来源。它们仅为呈现过滤：历史节点和关系不因滚动窗口而删除。近期词和已保留的历史关注词不受背景 1,200 词预算截断，旧词依据当前真实来源重新定位，不拷贝已失效的旧证据。来源内容真的删除或改变时，以当前可验证内容为准。

近期正文关联独立输出 `co_discussed/statistical`。采样单位是去重事件中的真实短分句（不超过 160 字、8 个词），边际和联合概率使用同一套样本；排除纯嵌套词片段，要求至少 2 个去重事件共同讨论且 NPMI≥.05，权重为 `NPMI * eventCount/(eventCount+2)`。这与基础图 `co_occurs` 的至少两来源组条件不同；事件数不写入来源家族计数。它只表示局部共同讨论，不能解释为因果、支持或对象同一性。联系不足时保留孤立词。

`attention`、观察日期和窗口改变 `stateHash`，不单独改变历史 `structureHash`。窗口推进和关注排序变化分别记录原因，旧快照继续保存在既有 Git 历史流程内。实测审计文件含原文，仅写入本地指定目录，不随插件包分发。
