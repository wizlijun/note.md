note.md + Grokbot

Grokbot produces the report. You read it in note.md, mark what matters, and keep your feedback beside the source for the next task.

Work through files

Grokbot — officially named Grok Bot — can work with Markdown documents. Give its outputs a home in your note.md vault: reports remain ordinary files, and your annotations stay available for follow-up work.

This workflow uses file access. It does not require a dedicated note.md connector.

Set up your vault

  1. In the Grok Bot desktop app, review Settings → Computer → Your computer → Execution on this computer. Use Ask every time to approve the local commands needed for your task.
  2. Give Grokbot the full path to your vault. Ask it to read the root AGENTS.md first; do not assume it discovers that file automatically. Use llms-full.txt as a reference for note.md conventions.
  3. Ask it to save a report as research/topic.md inside that vault.
  4. Open the report in note.md and add annotations. In the next task, ask Grokbot to read the paired research/topic.note.md before revising the report.

Local access and cloud work

Grok Bot's cloud computer is separate from your Mac or Windows computer. A path in its cloud /workspace is not a path in your local vault. Local command execution needs its own permission and may be restricted by your team's policy.

If local access is unavailable, attach selected Markdown files and save returned documents into the vault yourself. Attachments are a file handoff, not automatic synchronization. See the official guides to computers and apps, local permissions, and files and results.

Ask it to read your annotations

Try this after reviewing a report:

In my vault, read AGENTS.md, research/topic.md, and research/topic.note.md. Address the questions in my annotations, check the sources, and update research/topic.md. Keep my annotations unchanged and summarize what you changed.

The report and the feedback stay together, so you can continue the work in a later session or with another agent.

FAQ

Does this need a Grokbot plugin?

No dedicated note.md plugin is needed for this file workflow. Grokbot needs approved access to the relevant local files, or you can exchange selected files as attachments.

Will Grokbot automatically follow my vault rules?

Ask it to read AGENTS.md at the start of the task and review its changes. Keep your .note.md annotations human-owned; this workflow asks Grokbot to read them and edit the report instead.
