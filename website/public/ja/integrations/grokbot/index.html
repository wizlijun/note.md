note.md + Grokbot

Grokbot がレポートを作成し、あなたが note.md で読んで重要な箇所をマーク。フィードバックを原文のそばに残し、次の作業へ引き継ぎます。

ファイルを通じて連携する

Grokbot の正式名称は Grok Bot です。Markdown 文書を扱えるため、作成したレポートを note.md の Vault に保存できます。レポートは通常のファイルのまま残り、注釈も次の作業で参照できます。

この連携はファイルへのアクセスを使うため、専用の note.md コネクターは必要ありません。

Vault を設定する

  1. Grok Bot のデスクトップアプリで Settings → Computer → Your computer → Execution on this computer を開きます。Ask every time を使い、作業に必要なローカルコマンドをその都度承認します。
  2. Vault のフルパスを Grokbot に伝え、最初にルートの AGENTS.md を読むよう依頼します。自動で見つけるとは想定しないでください。note.md のファイル規約は llms-full.txt を参照できます。
  3. レポートを Vault 内の research/topic.md に保存するよう依頼します。
  4. note.md でレポートを開き、注釈を付けます。次の作業では、対応する research/topic.note.md を読んでからレポートを修正するよう依頼します。

ローカルアクセスとクラウドの違い

Grok Bot のクラウドコンピューターは、手元の Mac や Windows PC とは別の環境です。クラウドの /workspace にあるパスは、ローカルの Vault のパスではありません。ローカルコマンドの実行には個別の許可が必要で、チームのポリシーによって制限される場合もあります。

ローカルアクセスを使えない場合は、必要な Markdown ファイルを添付し、返された文書を自分で Vault に保存できます。添付はファイルの受け渡しであり、自動同期ではありません。詳しくは公式のコンピューターとアプリ、ローカル権限、ファイルと成果物の説明をご覧ください。

注釈を次の作業に生かす

レポートを確認したら、次のように依頼できます。

私の Vault にある AGENTS.md、research/topic.md、research/topic.note.md を読んでください。注釈の質問に対応し、出典を確認して research/topic.md を更新してください。私の注釈は変更せず、修正内容を簡潔に説明してください。

レポートとフィードバックが一緒に残るため、後のセッションや別のエージェントでも作業を続けられます。

FAQ

Grokbot のプラグインは必要ですか？

このファイル連携には専用の note.md プラグインは不要です。Grokbot に対象のローカルファイルへのアクセスを許可するか、必要なファイルを添付して受け渡します。

Grokbot は Vault の規則に自動で従いますか？

作業の最初に AGENTS.md を読むよう明示的に依頼し、変更内容を確認してください。.note.md の注釈はあなたが管理します。この手順では、Grokbot は注釈を読み、レポートを編集します。
