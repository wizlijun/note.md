# `.index.md` 格式 V1

文件名以 `.index.md` 结尾，例如 `阅读.index.md`。内容使用普通 Markdown 标题、段落和文件列表；没有 frontmatter 时默认显示为表格，无需 `type: index`。四种布局共用列表源码，`table` 只是界面布局名称，不需要编写表格标记。

## 可选配置

```yaml
---
view: board
group_by: 状态
lane_by: 项目
---
```

- `view`：`table`、`list`、`board` 或 `gallery`，省略时为 `table`。
- `group_by`：要分组的确切属性名；省略时按二级标题分组，无标题则“未分组”。
- `lane_by`：看板纵向泳道的确切属性名；省略时只有一个泳道。

普通 frontmatter 元数据可共存。用 YAML 字符串表达上述配置，不要将属性名写成数组。看板横向列使用 `group_by`，纵向泳道使用 `lane_by`；两个字段应按实际浏览目的选择。工具栏中的临时布局和分组选择不会回写配置。

## 内容结构

```markdown
# 文件目录

说明这一批文件的范围与字段来源。

## 查看器

- [需求清单](./需求清单.md)
  - 状态：待处理
  - 项目：查看器
  - 说明：整理文件导航需求

- [设计方案](./设计方案.md)
  - 项目：查看器
  - 状态：进行中

## 个人阅读

- [蓝色之书](./蓝色之书.md)
  - 作者：演示作者
  - 封面：![蓝色封面](./covers/blue-book.png)
```

以上路径仅用于解释语法；实际可打开的演示在 `../assets/`。

- 一级标题为页面标题，省略时使用文件名。说明段落或引用写在首个条目前、或二级标题后首个条目前；此处无列表符号的 `来源：本地文件` 等文字仍作为说明。
- 每个文件条目独占一行，使用一个标准 Markdown 文件链接，例如 `- [设计方案](./设计方案.md)`。列表符号支持 `-`、`*`、`+`、`1.` 或 `1)`；主链接外不放其他内容。
- 属性推荐写为 `  - 字段：值`，中英文冒号均支持，也可省略属性前的列表符号。属性名使用普通文本，值可留空；“文件”为主链接的保留字段，不可覆盖，属性名也不以 `[` 或 `![` 开头，以免损坏链接被误当成属性。
- 属性按文件顺序归最近的前一个文件条目，直到下一条文件链接或二级标题出现。空行不会结束条目。缩进不表达层级：空格或 tab 增减不会改变属性归属。
- 不要求每条属性齐全或顺序相同。查看器按属性首次出现顺序取并集，缺失属性补空；没有证据的值可省略或留空。同一文件条目内不能重复属性名，避免不明确的覆盖。
- 属性值可用普通文本、强调、行内代码、普通 Markdown 链接和图片。正文属性在同一行写完；条目内不要写不带属性名的游离说明或多行续文。
- 任意属性中遇到的第一张图片用作封面，例如 `  - 封面：![演示书封面](./covers/blue-book.png)`。
- 不使用 Markdown 表格、代码围栏、逐项 YAML 或 HTML 承载索引数据；原始 HTML 不会执行。

以下两种写法具有相同含义。推荐输出第一种规范缩进，手工编辑时缩进增减不影响解析：

```markdown
- [设计方案](./设计方案.md)
  - 状态：进行中
  - 项目：查看器
```

```markdown
    - [设计方案](./设计方案.md)
- 状态: 进行中
       项目：查看器
```

## 链接与封面

链接和图片地址相对索引文件解析，也可用 `../` 指向 Vault 内其他目录。目标规范化后必须仍在同一 Vault 内；不使用网络 URL、脚本 URL、系统绝对路径或越界路径。文件名含空格时可用标准 Markdown 尖括号目的地，例如 `[会议记录](<./会议 记录.md>)`；生成后按真实路径核对。

封面仅支持 Vault 内 PNG、JPEG、WebP、GIF，不引用远程封面或 SVG。无图时留空即可；损坏或无法读取的图片显示占位及提示，不影响其他条目。点击文件链接打开原文件；查看器不下载图片、不改原文件、不支持拖拽修改看板状态。

## 四种布局

- `table`：把列表中的属性显示为多列表格，适合对比多个属性、批量浏览，可省略配置。
- `list`：按 `group_by` 或二级标题分组，适合按主题、类别导航。
- `board`：用 `group_by` 设置横向列，需要二维视图时加 `lane_by`，适合状态 × 项目、阶段 × 负责人。
- `gallery`：属性中放本地 Markdown 图片，适合书籍、画册、带封面的资料。

切换布局无需复制内容或定义四份数据。看板的横向分组数乘以纵向泳道数超过 400 时，会提示先搜索缩小范围或选择其他分组字段，避免生成难以浏览的巨大矩阵；原始数据仍完整保留。

## 校验与回退

容错只处理缩进、属性顺序与缺失字段，不猜测含混内容。未知 `view`、不存在的配置属性、同一条目的重复属性、带列表符号的属性出现在文件条目前、主链接混有其他内容、条目内游离说明以及不支持的结构都会令查看器整体回退 Markdown，不静默跳过错误条目。生成后检查每条实际链接；如果 Agent 环境可以使用项目解析器，再运行 `parseIndex(content, uri)` 确认返回有效文档。
