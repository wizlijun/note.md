# 四类索引生成 prompt

将花括号内容替换为真实范围和输出路径。支持 skill 的 Agent 可使用 `$file-index`；未安装时将本 skill 目录提供给 Agent，要求读取 `SKILL.md`。以下请求只授权创建索引。四种布局的源码都用文件列表和“字段：值”属性，不写 Markdown 表格；属性推荐缩进两格，缺失字段可省略，属性顺序不必对齐。

## 多列表格视图

> 使用 $file-index，为 `{Vault 内目录}` 的现有 Markdown 文件生成 `{输出目录}/资料.index.md`，使用 table 布局，但源码写成列表。先盘点实际文件，每个文件写一条独占一行的 Markdown 链接，后面根据内容写“主题、作者、日期、说明”属性。没有证据的属性省略或留空，在说明中简述字段来源。使用相对链接，验证所有目标存在且在 Vault 内；不要改写源文件。

## 分组列表

> 使用 $file-index，为 `{Vault 内目录}` 生成 `{输出目录}/导航.index.md`，使用 list 布局，按“类别”属性分组。每条文件链接后写“类别、说明”属性。类别优先采用文件中已有标签；缺少标签时，仅在正文有明确依据时分类，并在说明里交代分类原则，不确定时留空。链接真实文件，使用列表源码，不写 Markdown 表格。索引应便于阅读和点击导航，不要移动文件。若用户已有明确的章节目录，也可用二级标题分节并省略 group_by。

## 泳道看板

> 使用 $file-index，检查 `{Vault 内项目目录}`，生成 `{输出目录}/项目看板.index.md`。使用 board 布局，横向按“状态”分组，纵向按“项目”建立泳道，配置 group_by 为“状态”、lane_by 为“项目”。每个列表条目对应一个真实文件，文件链接独占一行，后面写“状态、项目、负责人、说明”属性。状态和负责人只采用文件或我提供的信息，未知省略或留空，不按文件名自行推断进度。属性采用“字段：值”列表写法，不写 Markdown 表格，同一条目不重复属性名。使用相对链接，并说明这是只读索引；不要更改项目文件。

## 书籍封面网格

> 使用 $file-index，为 `{Vault 内读书目录}` 的真实书籍笔记生成 `{输出目录}/书架.index.md`，使用 gallery 布局，按“阅读状态”分组。每本书用一个列表条目，书名链接笔记并独占一行，后面写“作者、阅读状态、主题、封面”属性。读取笔记中已有的作者、主题与阅读状态；未知省略或留空。仅引用 Vault 内已存在且能确认属于该书的 PNG、JPEG、WebP 或 GIF 封面，封面属性使用 Markdown 图片和相对链接；缺图留空，不下载封面、不虚构书目、不修改笔记。所有数据采用列表源码，不写 Markdown 表格。检查所有链接和封面目标后交付。
