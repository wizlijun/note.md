# 四类索引生成 prompt

将花括号内容替换为真实范围和输出路径。支持 skill 的 Agent 可使用 `$file-index`；未安装时将本 skill 目录提供给 Agent，要求读取 `SKILL.md`。以下请求只授权创建索引。

## 多列表格

> 使用 $file-index，为 `{Vault 内目录}` 的现有 Markdown 文件生成 `{输出目录}/资料.index.md`，使用 table 布局。先盘点实际文件，再根据文件内容提取“文件、主题、作者、日期、说明”列，第一列链接到源文件。没有证据的字段留空，在说明中简述字段来源。使用相对链接，验证所有目标存在且在 Vault 内；不要改写源文件。

## 分组列表

> 使用 $file-index，为 `{Vault 内目录}` 生成 `{输出目录}/导航.index.md`，使用 list 布局，按“类别”列分组。类别优先采用文件中已有标签；缺少标签时，仅在正文有明确依据时分类，并在说明里交代分类原则，不确定时留空。保留“文件、类别、说明”列，链接真实文件。索引应便于阅读和点击导航，不要移动文件。若用户已有明确的章节目录，也可用二级标题分节并省略 group_by。

## 泳道看板

> 使用 $file-index，检查 `{Vault 内项目目录}`，生成 `{输出目录}/项目看板.index.md`。使用 board 布局，横向按“状态”分组，纵向按“项目”建立泳道，配置 group_by 为“状态”、lane_by 为“项目”。每行对应一个真实文件，列为“文件、状态、项目、负责人、说明”。状态和负责人只采用文件或我提供的信息，未知留空，不按文件名自行推断进度。使用相对链接，并说明这是只读索引；不要更改项目文件。

## 书籍封面网格

> 使用 $file-index，为 `{Vault 内读书目录}` 的真实书籍笔记生成 `{输出目录}/书架.index.md`，使用 gallery 布局，按“阅读状态”分组。保留“书名、作者、阅读状态、主题、封面”列，第一列链接书籍笔记。读取笔记中已有的作者、主题与阅读状态；未知留空。仅引用 Vault 内已存在且能确认属于该书的 PNG、JPEG、WebP 或 GIF 封面，使用 Markdown 图片和相对链接；缺图留空，不下载封面、不虚构书目、不修改笔记。检查所有链接和封面目标后交付。
