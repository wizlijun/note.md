# 文件索引

先读 [格式说明](references/format.md)，盘点用户指定范围内的实际文件，再生成 `.index.md`。遵循用户已选布局；未指定时默认用标题分类的列表，比较字段用表格、两个维度交叉浏览用泳道看板、已有本地封面用封面网格。

## 生成原则

- 先查文件名，再按所需字段读取内容。只索引指定范围内确实存在的文件；输出位置决定相对链接的基准。
- 用 `#` 写索引标题，`##` 至 `######` 写分类层级。分类优先采用用户已有目录或有依据的主题，分类说明写在相应标题下。层级由标题决定，不由文件列表缩进决定。
- 每个文件只写一行：`- [标题](./文件.md) [状态:: 进行中] #主题/设计 一句话说明`。自定义属性为 `[字段:: 值]`，未知可省略或留空，属性值可含空格、链接和图片。不要写子属性列表、表格源码或逐项 YAML。
- 标题、作者、状态、项目来自文件名、frontmatter、正文或用户信息。不要从文件存在推测完成状态；标签不自动映射成状态或项目。同一行不重复字段，`文件`、`标签`、`说明` 保留给主链接、行内标签和尾文自动生成。
- 封面写为 `[封面:: ![封面](./covers/book.png)]`，仅引用确实存在且属于该条目的 Vault 内 PNG、JPEG、WebP、GIF；缺图省略，不编造路径或自动下载。
- 逐一验证相对链接目标存在且仍在 Vault 内，保留源文件。索引生成本身不授权改写、移动源文件或获取外部内容。
- 交付前检查一文件一行、分类归属、字段无重复、配置字段确实出现；说明输出位置、显示布局及无法确认的重要信息。

## 模板与提示词

按所需布局读取一份模板：[表格](assets/table.index.md)、[分组列表](assets/list.index.md)、[泳道看板](assets/board.index.md)、[封面网格](assets/gallery.index.md)。模板的 `examples/` 和 `covers/` 是本 skill 的演示资产，生成真实索引时替换演示条目，不混入用户文件范围。

可复制请求见 [四类 prompt](references/prompts.md)。需要理解 Notion、Obsidian 与行内字段的兼容边界时，读 [参考与取舍](references/design-notes.md)；它不是查询语言或数据库同步插件。
