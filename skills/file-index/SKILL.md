# 文件索引

先读 [格式说明](references/format.md)，按用户指定范围盘点实际文件，再生成可由 Index Viewer 打开的 `.index.md`。遵循用户已选布局；未指定时，比较字段用表格、分类导航用列表、两个维度交叉浏览用泳道看板、已有本地封面用封面网格。

## 生成原则

- 只纳入指定范围内确实存在的文件。先搜索文件名，再按所需字段读取内容；输出索引的位置决定相对链接的基准。
- 标题、作者、状态、项目等字段来自文件名、frontmatter、正文或用户明确提供的信息。不要从“文件存在”推测完成状态，未知值留空；必要时在索引说明中交代字段来源和缺失情况。
- 所有布局都使用列表源码：`- [标题](./文件.md)` 独占一行，属性推荐写为缩进两格的 `- 字段：值`。不写 Markdown 表格、逐项 YAML 或特殊指令。
- 属性归最近的前一个文件条目，缩进多一格、少一格或改用 tab 都不改变归属。属性可省略列表符号；字段顺序可不同、未知字段可省略或留空。同一条目内不要重复属性名；二级标题开始新分节。
- 封面仅引用已存在的 Vault 内 PNG、JPEG、WebP、GIF。缺少封面时留空，不捏造路径、不自动下载图片。
- 为索引写入相对链接并逐一确认目标存在、解析后仍在 Vault 内。保留源文件；索引生成本身不授权改写、移动源文件或获取外部内容。
- 交付前检查配置属性名确实出现、每条主链接独占一行、没有重复属性名。结果应说明输出位置、布局及未能确认的重要字段。

## 模板与提示词

按所需布局读取一份模板：[表格](assets/table.index.md)、[分组列表](assets/list.index.md)、[泳道看板](assets/board.index.md)、[封面网格](assets/gallery.index.md)。模板的 `examples/` 和 `covers/` 都是本 skill 的演示资产，不是用户知识；生成真实索引时替换演示条目，不把它们混入用户的文件范围。

需要可复制的完整请求时，读 [四类自然语言 prompt](references/prompts.md)。所有格式约束以 [格式说明](references/format.md) 为准。
