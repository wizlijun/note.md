# Connect note.md vault search to Claude (setup instructions)

These instructions were generated by note.md 0.0.0-snapshot for this Mac. The paths
below are valid only on this machine. If note.md is moved, generate them again
in note.md → Settings → "Copy setup instructions for Claude".

note.md serves read-only `search` and `vault_info` tools over MCP (stdio). It
never writes to the vault. Registering it means adding one entry to each Claude
app's own configuration — nothing else.

## 1. Rules for the agent reading this

1. First check whether you can run commands on this Mac itself:

   ```sh
   uname -s && test -x '/Applications/note.md.app/Contents/MacOS/notemd' && echo notemd-ok
   ```

   Continue only if the output is `Darwin` followed by `notemd-ok`.
2. If you cannot run commands, or the check fails (for example you are inside
   Cowork's Linux VM, or in a chat without a shell): **do not attempt any
   step**. Show the user section 5 verbatim and stop.
3. Before every change, show the user the exact change and wait for their
   confirmation. Change only the single entry named below; leave every other
   setting untouched.

## 2. Claude Code

Check for an existing entry:

```sh
claude mcp get notemd
```

- Not found → after confirmation, run:

  ```sh
  claude mcp add --scope user notemd -- '/Applications/note.md.app/Contents/MacOS/notemd' --cli mcp
  ```

- Found with a different command or arguments → show the difference; after
  confirmation, run `claude mcp remove notemd --scope user`, then the command above.
- Found and identical → nothing to do.

## 3. Claude Desktop (Chat and Cowork)

File: `~/Library/Application Support/Claude/claude_desktop_config.json`

Set exactly one key, `mcpServers.notemd`, to:

```json
{
  "command": "/Applications/note.md.app/Contents/MacOS/notemd",
  "args": ["--cli", "mcp"]
}
```

- Keep every other key in the file as it is. Use a JSON-aware tool; never edit
  the file by text substitution.
- If the file does not exist, create it with only this content:

  ```json
  {
    "mcpServers": {
      "notemd": {
        "command": "/Applications/note.md.app/Contents/MacOS/notemd",
        "args": ["--cli", "mcp"]
      }
    }
  }
  ```

- Before writing, copy the existing file to
  `claude_desktop_config.json.bak-<YYYYMMDD-HHMMSS>` in the same folder.
- After writing, parse the file again to confirm it is valid JSON.
- Tell the user to quit Claude completely (⌘Q) and open it again. Desktop reads
  this file only at startup.

## 4. Self-check

```sh
printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"notemd-setup-check","version":"1"}}}' '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' | '/Applications/note.md.app/Contents/MacOS/notemd' --cli mcp
```

Success: two JSON lines are printed, and the second contains both `"search"`
and `"vault_info"`. This does not need note.md to be open (running it may start
note.md in the background, which is expected).

## 5. Manual setup (for the user)

1. Claude Desktop (Chat and Cowork): open
   `~/Library/Application Support/Claude/claude_desktop_config.json` (Claude →
   Settings → Developer → Edit Config), add this entry under `"mcpServers"`,
   then quit Claude with ⌘Q and reopen it:

   ```json
   "notemd": {
     "command": "/Applications/note.md.app/Contents/MacOS/notemd",
     "args": ["--cli", "mcp"]
   }
   ```

2. Claude Code: run in Terminal:

   ```sh
   claude mcp add --scope user notemd -- '/Applications/note.md.app/Contents/MacOS/notemd' --cli mcp
   ```

3. Verify in Cowork: start a new task and ask Claude to call notemd's
   `vault_info`. Setup is complete when `mount.status` is `matched`.

## 6. Troubleshooting

- Claude Desktop log: `~/Library/Logs/Claude/mcp-server-notemd.log`
- A tool says note.md is not running → open note.md and try again.
- note.md was moved or reinstalled elsewhere → generate these instructions again.
